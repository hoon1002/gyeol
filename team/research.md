### 3-2. 2025~26 공통 기법 (차용 우선순위 순)

1. **CSS 스크롤 연동 애니메이션 + View Transitions**: JS 없이 스크롤·화면 전환 연출. `transform`·`opacity`만 움직여 성능을 지킴 [S29] (브라우저 지원은 caniuse로 재확인 필요)
2. **키네틱·초대형 타이포 + 가변 폰트**: 굵기·폭을 스크롤·호버에 따라 부드럽게 변화. 폰트 파일 하나로 여러 굵기 [S29]
3. **벤토 그리드**: 크기가 다른 카드 모듈로 대시보드 구성(오늘 할 일·복습 큐·타이머·D-day) [S29]
4. **다크 모드를 기본 정체성으로**, 고대비 액센트 1색 (Lando Norris 사례)
5. **WebGL/Three.js 3D는 한 곳에 집중**: 수상작도 3D가 정체성 한 장면을 맡고 나머지는 2D UI
6. **의미 있는 마이크로 인터랙션 + `prefers-reduced-motion` 존중 + WCAG 2.2** [S29]

### 3-3. 디자인이 뛰어난 생산성 앱의 UI 원칙

## 4. 차별화 기회 (8개)

| # | 기회 | 경쟁사가 못 하는 이유 | 우리의 방식 |
|---|---|---|---|
| D1 | **강의 하나가 하나의 흐름** | 각 앱이 필기·정리·연결·암기·집중 중 1~2단계만 맡음 (1장 결론) | 시간표의 강의 → 강의 PDF 불러오기 → 필기 → 올가미로 표시한 부분이 카드·개념 노드로 → 복습 큐 → 시험 D-day에서 거꾸로 계산한 복습 계획 |
| D2 | **손필기에서 바로 복습 카드** | 굿노트·삼성 노트는 카드 기능이 없고, RemNote는 텍스트 중심, Anki는 수작업 [S18] | 필기 영역을 올가미로 선택 → 앞면/뒷면 또는 가림 카드 → FSRS로 자동 일정 |
| D3 | **손필기와 타이핑 노트가 같은 그래프에** | Heptabase·Obsidian은 손필기가 없고, 굿노트는 링크·백링크가 없음 | 필기 페이지의 특정 영역에도 `[[링크]]`·백링크. 그래프에 손필기 노드가 함께 뜸 |
| D4 | **시간 × 내용 × 기억률 대시보드** | 열품타는 공부 시간만, Anki는 기억률만 보여 줌 | 뽀모도로 세션이 어떤 과목·노트에 쓰였는지 자동 기록 + 카드 기억률 → "어디에 시간을 썼고, 아직 무엇을 모르는지" |
| D5 | **녹음 ↔ 필기 ↔ 슬라이드 타임싱크** | Notability만 강하고, 정리·카드와는 연결되지 않음 | 강의 녹음 재생 시 필기가 다시 그려지고, 그 순간에서 바로 카드 생성 |
| D6 | **무료·로컬 우선·기기 무관** | 구독 피로(굿노트·Quizlet·Notability)와 기기 종속(굿노트 iOS 전용 설정, 삼성 노트) [S1][S3][S10][S13] | 브라우저 하나로 아이패드·갤탭·노트북에서 펜 지원(필압·기울기), 오프라인 동작, 마크다운·PDF·`.apkg` 내보내기 보장 |
| D7 | **꾸미기 0분 학기 셋업** | 노션은 템플릿을 찾고 고치는 데 시간이 듦 [S17] | 시간표만 입력(또는 붙여넣기)하면 과목 공간·주차별 페이지·시험일이 자동 생성 |
| D8 | **경쟁보다 성장 중심의 동기 설계 + 수상작급 모션** | 경쟁 앱 UI는 실용 위주, 동기 앱은 랭킹 중심 | "어제의 나"와 비교, 공부할수록 자라는 작은 세계(Forest·Messenger 메타포). 모션은 복습 완료·연결 생성 같은 학습 피드백에 쓰고, 시험 기간 집중 모드에선 최소화 |

## 5. 기획자·디자이너가 바로 쓸 핵심 시사점 10줄

1. **핵심 가치는 "흩어진 6개 앱을 한 흐름으로"**: 경쟁사 중 손필기부터 복습까지 잇는 앱은 없다. 기능 나열보다 **강의 단위 파이프라인(D1)**을 첫 화면 이야기로.
2. **필기 → 복습 연결(D2)이 가장 날카로운 쐐기**: "필기는 하는데 다시 안 본다"(P2·P3)를 정면으로 해결. MVP에 올가미 → 카드 → FSRS를 꼭 넣을 것.
3. **시간표가 출발점**: 에브리타임식 시간표로 과목 공간을 자동 생성(D7). 노션식 꾸미기 부담(P7)을 없앤다.
4. **무료·로컬 우선·내보내기 보장을 신뢰의 메시지로**: 구독 피로(P5)와 유실 불안(P8)이 크다. "내 데이터는 내 기기에, 언제든 꺼낼 수 있다"를 UI 문구로도 드러낼 것.
5. **펜 경험이 승부처**: 굿노트·삼성 노트 사용자를 데려오려면 필압·손바닥 무시·지연이 네이티브에 근접해야 한다. 아이패드와 갤탭을 모두 1급 대상으로.
6. **집중 타이머는 단독 기능이 아니라 데이터 수집기**: 뽀모도로 세션을 과목·노트에 묶어 시간×기억률 대시보드(D4)로. 랭킹보다 개인 성장 중심(D8).
7. **디자인 정체성은 Lando Norris식 "2색 + 시그니처 액센트 1색"**: 다크 기본, 고대비. 3D·셰이더는 랜딩·온보딩·집중 모드의 "작은 세계" 한 장면에만 집중한다.
8. **앱 본체는 Linear·Things처럼 빠르고 차분하게**: Cmd+K 명령 팔레트, 한 글자 단축키, 낙관적 UI. 공부 중 화면에선 화려함보다 반응 속도가 우선.
9. **모션은 학습 피드백에 쓴다**: 카드 복습 완료, 개념 연결, 스트릭에 의미 있는 마이크로 인터랙션(Anime.js식 스프링·순차 등장). `prefers-reduced-motion`과 집중 모드에선 줄인다.
10. **반응형은 "같은 화면 축소"가 아니라 기기별 역할 분담**: 폰은 복습 카드·타이머·빠른 메모, 태블릿은 펜 필기·PDF, 데스크톱은 정리·그래프·대시보드(벤토 그리드). View Transitions로 기기·화면 간 전환의 연속성을 준다.
