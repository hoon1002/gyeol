## 0. 공통 약속

### 0-1. 이름

| 이름 | 뜻 |
|---|---|
| 종이 | 필기 노트 화면에서 쪽들이 세로로 이어진 면 |
| 맞춤 100% | 쪽 너비가 종이 칸 너비에 꼭 맞는 확대 |
| 도구 칸 | 떠 있는 알약. 상태는 **펼침**과 **구슬**(접힘) 둘 |
| 둥근 메뉴 | 길게 누르면 누른 자리에 뜨는 고리 모양 메뉴 |
| 선택 칸 | 고른 것 옆에 뜨는 작은 알약 |
| 쪽 서랍 | 왼쪽에서 들어오는 쪽 썸네일 판 |
| 테이프 칩 | 테이프가 있는 쪽의 모서리에 붙는 숫자 칩 |
| 쪽 번호 | 넘기는 동안만 보이는 "3 / 12" |

### 0-2. 입력 판정

숫자는 한 파일(예: `src/ink/input/thresholds.ts`)에만 두고, 앱 A와 엔진이 같은 상수를 쓴다.

| 판정 | 값 |
|---|---|
| 누르기 / 끌기 | 이동 < **6px**이고 길게 누르기 시간 전에 떼면 누르기. 6px를 넘으면 끌기이고, 끌기 뒤의 click은 버린다(브리프 D). 여러 손가락 탭만 **250ms** 안이어야 한다 |
| 손가락 길게 누르기 | **450ms**, 이동 < 10px |
| 펜 길게 누르기(빈 곳) | **600ms**, 이동 < 4px. 300ms부터 펜 끝에 고리 예고(3-1) |
| 마우스 | 오른쪽 클릭 = 즉시. 왼쪽 길게 600ms |
| 두 손가락 탭 | 두 접점이 내려온 시각 차 ≤ 80ms, 둘 다 250ms 안에 뗌, 각 이동 < 10px, 두 점 거리 변화 < 6%(핀치가 아님) |
| 세 손가락 탭 | 같은 기준, 세 접점의 시각 차 ≤ 100ms |
| 두 손가락 대고 있기 | 600ms 뒤부터 연속 되돌리기, 120ms마다 1단계. 떼면 멈춘다 |
| 핀치 · 두 손가락 끌기 | 두 점 거리 변화 ≥ 6%면 핀치, 중점 이동 ≥ 10px면 끌기. 둘이 함께 일어나도 된다 |
| 확대 범위 | 맞춤 100% 기준 **50–400%**. 손을 뗐을 때 94–106%면 100%로 붙는다(200ms `--ease-out`) |
| 도형 다듬기 | 획 끝에서 **500ms** 멈춤, 이동 < 4px |
| 형광펜 곧게 | 획 끝에서 300ms 멈춤. 또는 직선에서 벗어난 폭 < 획 길이의 6%면 떼는 순간 곧게 |
| 가장자리 밀기 | 손가락만. 시작 x ≤ 20px, 가로 이동 ≥ 24px, 가로/세로 > 1.5, 처음 120ms 안 |
| 손바닥 | 접점 width·height > 40px는 버린다. 펜이 닿아 있는 동안 손가락은 모두 무시한다. 펜을 뗀 뒤 300ms 동안은 펜 마지막 점에서 120px 안에서 시작한 손가락을 무시한다 |
| 빈 곳 | 누른 점 12px 안에 획·물건이 없음 |

### 0-3. 층 순서 · Esc · 뒤로

위에서 아래로 쌓는다. Esc와 브라우저 뒤로는 **맨 위 하나만** 닫는다.

1. 툴팁
2. 색·굵기·도구 옵션 팝오버
3. 둥근 메뉴
4. 무음 안내 카드
5. 고름(선택 칸)
6. 쪽 서랍
7. 더 보기 줄
8. 노트

- 아무것도 열려 있지 않을 때 Esc는 **아무 일도 하지 않는다**(쓰던 노트가 실수로 닫히지 않게 한다).
- 브라우저 뒤로, ‹, ⌘K '노트 닫기'만 노트를 닫는다.
- 위 1–4번이 열려 있을 때의 두 손가락 탭은 그 층만 닫는다. 이때 되돌리기는 하지 않는다.

### 0-4. 명령 하나, 입구 여럿

- 잉크 기능은 모두 `INK_COMMANDS`에 하나씩 등록한다. 한 줄에 id · ⌘K 이름 · 별칭 · 단축키 · 아이콘 · 실행 함수를 둔다(부록 A).
- 버튼, 제스처, 둥근 메뉴, 키는 모두 같은 id를 부른다.
- **⌘K에 없는 기능은 없다.** 시험으로 확인한다: 등록된 id는 모두 ⌘K 검색 결과에 나와야 한다.
- 노트 화면에서는 ⌘K 맨 위에 '잉크' 묶음이 먼저 나온다. 줄 오른쪽에는 단축키를 모노 11px로 쓴다.

### 0-5. 성능 규칙 (펜 → 잉크 다음 프레임)

- **잉크 화면에 떠 있는 것에는 `backdrop-filter`를 쓰지 않는다.** 대신 불투명에 가까운 `--surface-2` 96%를 쓴다. 이유: 아래 캔버스가 매 프레임 바뀌면 blur를 매번 다시 계산한다.
- 떠 있는 것의 애니메이션은 `transform` · `opacity` · `clip-path`만 쓴다. 도구 칸이 접히고 펴질 때도 레이아웃은 바뀌지 않는다(2-3).
- **잉크 입력은 하늘을 깨우지 않는다.** 종이 위 pointer 이벤트는 엔진 `kick()`을 부르지 않는다. 하늘은 노트를 여닫을 때만 움직인다(10장).
- 도구 칸 접힘은 첫 잉크를 그린 **다음** rAF에 시작한다. 첫 프레임은 잉크에게 준다.

## 1. 노트를 여는 모습

### 1-1. 들어가는 문

| 문 | 결과 |
|---|---|
| 노트 목록에서 필기·PDF 노트 누르기 | 1-4 여는 모션 |
| 새 노트 버튼을 **펜으로** 누르기 | 빈 필기 노트(틀은 마지막에 쓴 것, 처음은 줄)를 바로 연다 |
| 새 노트 버튼을 손가락·마우스로 누르기 | 글 노트(M2 그대로) |
| 새 노트 버튼 길게 누르기 | 둥근 메뉴 3칸: 글 노트(12시) · 필기 노트(4시) · PDF 가져오기(8시) |
| 오늘 수업 노트 줄(점선)을 펜으로 누르기 | 코넬 틀 필기 노트, 제목 "10.17 물리" |
| PDF를 노트 목록에 끌어 놓기(데스크톱) | PDF 노트(첫 쪽부터 PDF 배경) |

- **입력한 손이 정한다**(결정 4): 펜은 필기를, 손가락·키보드는 글을 연다. 메모 칸도 같다(8-1).
- 제목은 종이에 쓰지 않는다. 자동 제목("10.17 필기" 또는 수업 노트 제목)이 붙고, 쪽 서랍 머리에서 고친다(5-2).

## 2. 도구 칸

### 2-1. 모양 · 치수

```
 펼침 (펜일 때, 터치 기기)
 ╭─────────────────────────────────────────────────────╮
 │ [펜] [형광] [지우개] [올가미] [테이프] │ (●)(●)(●) [굵기] │ [⋯] │
 ╰─────────────────────────────────────────────────────╯
   └─ 도구 5: 움직이지 않음 ─┘   └─ 가운데 칸: 도구마다 다름 ─┘

 구슬 (쓰는 동안)          ╭───╮
                           │ ✒ │  ← 지금 도구 버튼 자리에 그대로 남는다
                           ╰─•─╯     아래 4px 점 = 지금 색
```

| 항목 | 터치(`pointer: coarse`) | 마우스(`pointer: fine`) |
|---|---|---|
| 칸 높이 | 48 | 40 |
| 버튼(누르는 영역 / 보이는 면) | 44 / 40 | 36 / 32 |
| 아이콘 | 22px, 선 1.5 | 20px, 선 1.5 |
| 안쪽 여백 · 버튼 사이 | 2 · 0 | 2 · 0 |
| 칸 나눔 | 1×20px `--border`, 좌우 6px | 같음 |
| 면 | `--surface-2` 96%, 1px `--border`, `--shadow-2`, 모서리 999. **blur 없음** | 같음 |
| 펼친 너비(펜일 때) | ≈ 470px | ≈ 390px |

- **지금 도구:** 아이콘 `--text-1` + 아이콘 아래 6px에 4px 점(지금 색. 지우개·올가미는 `--text-1`). 레일의 '지금 장소 점'과 같은 말투다. 다른 도구는 `--text-2`.
- **색 점:** 지름 20px. 밤 종이면 밤 표시 색, 낮이면 저장 색. 고른 점은 3px 떨어진 2px 고리(`--text-1`)를 두른다.
- **굵기 버튼:** 지금 색의 점 하나로 보인다. 지름은 가늘게 6 · 보통 10 · 굵게 14px.
- 버튼을 누르면 scale .92(80ms) → 1(160ms `--ease-out`).

### 2-2. 가운데 칸은 도구마다 다르다

| 도구 | 가운데 칸 |
|---|---|
| 펜 · 형광펜 · 테이프 | 색 3 + 굵기 |
| 지우개 | 방식 2(획 통째 · 부분) + 크기 |
| 올가미 | 없음(칸이 줄어든다) |
| 한 번 도구(도형 · 글 상자 · 사진) | 펜과 같다(펜의 색·굵기를 쓴다) |

- **도구 버튼 5개는 절대 움직이지 않는다.** 칸은 도구 쪽 끝(가로면 왼쪽, 세로면 위쪽)에 고정하고, 가운데 칸만 늘고 준다. 이렇게 해야 도구를 바꿀 때 손가락 아래 버튼이 밀리지 않는다.
- 늘고 줄 때: 바탕 `clip-path` 180ms `--ease-out`, 새 내용 opacity 0 → 1 120ms.

### 2-3. 접힘 · 펴짐

| 바뀜 | 조건 | 모션 |
|---|---|---|
| 펼침 → **구슬** | 종이에서 잉크 도구(펜·형광펜·지우개·올가미·테이프)의 획이 시작되면, 첫 잉크를 그린 다음 rAF | 나머지 버튼 opacity 0(80ms), 바탕 clip-path가 지금 도구 버튼으로 줄어든다(160ms `--ease-out`). 지금 도구 버튼은 제자리에 있다 |
| 구슬 → 펼침 (쉼) | 마지막 획이 끝나고 **2.4초** 동안 종이 입력 없음 · 화면에 손가락 없음 · 마지막 획 끝점이 펼친 칸 사각형에서 160px 밖 | 바탕이 펴진다(220ms `--ease-out`), 버튼은 지금 도구에서 먼 쪽으로 20ms 간격 opacity 0 → 1 |
| 구슬 → 펼침 (즉시) | 구슬 누르기 · 펜 호버가 구슬 96px 안에 120ms 머묾 · 마우스가 구슬 위에 올라옴 | 같음 |
| 계속 구슬 | ⌘K '도구 칸 늘 접기'를 켬 | 누를 때만 펴진다 |

- **구슬:** 지름 44(마우스 36). 지금 도구 아이콘과 4px 색 점을 두고, 테두리는 1px 지금 색 40%다. 펜이 닿아 있는 동안 opacity .72, 떼면 1.
- **배우는 규칙:** 자동으로 펴진 뒤 1.5초 안에 다시 쓰기 시작한 일이 **연달아 3번**이면, 이 노트를 닫을 때까지 쉼 기준을 2.4초에서 **6초**로 늘린다. 생각하며 자주 멈추는 사람에게 칸이 깜빡이지 않게 하려는 것이다.
- 펼친 칸에서 지금 도구를 한 번 더 누르면 도구 옵션이 열린다(2-5).

### 2-4. 자리 · 끌어 옮기기

- 네 가장자리에 붙는다. 위·아래는 가로, 왼쪽·오른쪽은 세로다.
- **끌기:** 칸(구슬 포함)의 아무 곳이나 누르고 6px 넘게 움직이면 끌기가 된다. 그 누름의 버튼 동작은 취소된다.
- **끄는 동안:** scale 1.04, `--shadow-3`. 손을 따라가고 지연은 없다.
- **놓으면:** 가장 가까운 가장자리에 붙는다. 그 가장자리를 따라가는 좌표는 놓은 자리 그대로다. 단, 모서리에서 24px, 뒤로·쪽 번호에서 12px 떨어지게 자른다. 320ms `--ease-spring`.
- 가로 ↔ 세로가 바뀌면 버튼 배치를 FLIP 200ms로 옮긴다.
- **가장자리 여백:** 위 = 안전 영역 + 10, 아래 = 안전 영역 + 12, 왼쪽·오른쪽 = 12.
- **저장:** `meta['ink.dock.<phone|port|land>'] = { edge, t }`(t = 가장자리 위 0–1).
- 폰은 위·아래만 된다.

### 2-5. 도구 옵션 (지금 도구를 한 번 더 누르기 · 아무 도구나 길게 누르기)

- **팝오버:** 칸에서 8px 떨어져 뜬다(칸이 위면 아래, 세로면 옆). `--surface-2` 96%, 모서리 14, 안쪽 8.
- **첫 줄:** 도구 이름(13px `--text-2`). 이것이 이 팝오버의 글 1줄이다.
- **그 아래:** 아이콘 세그먼트(36px)를 둔다.

| 도구 | 옵션 |
|---|---|
| 펜 | 결: 볼펜 · 만년필 · 연필 / 압력: 켬 · 끔 |
| 형광펜 | 곧게: 켬(기본) · 끔 |
| 지우개 | 다 지우면 이전 도구로: 켬 · 끔(기본 끔) |
| 올가미 · 테이프 | 이름만 보인다(옵션 없음) |

### 2-6. 색 3칸 · 색 고르기

- 색 점을 누르면 그 색을 쓴다. 이미 고른 점을 다시 누르거나 길게 누르면 **색 팝오버**가 열린다.
- **색 팝오버:**
  - 견본은 28px이다. 펜은 6×2(12색), 형광은 6×1, 테이프는 6×1이다.
  - 펜만 맨 끝에 '직접' 원(무지개 테두리)을 둔다. 누르면 `<input type="color">`(iPad는 시스템 색 고르기)가 열린다.
- 견본을 누르면 **그 칸을 바꾸고** 닫는다.
- 칸 색은 도구마다 따로 `meta['ink.tools']`에 저장한다.

### 2-7. 굵기

- 굵기 버튼을 누르면 버튼 아래로 점 3개(36px 칸)가 펼쳐진다(140ms). 고르면 닫힌다.
- 점을 길게 누르면 미세 조절 막대(가로 160px)가 나온다.
- 굵기는 **쪽 좌표 pt**다. 확대하면 종이처럼 함께 커진다.

| 도구 | 가늘게 | 보통(기본) | 굵게 | 막대 범위 |
|---|---|---|---|---|
| 펜(볼펜·만년필) | 1.2 | 2.0 | 3.2 | 0.5–8 |
| 펜(연필) | 1.0 | 1.6 | 2.6 | 0.5–6 |
| 형광펜 | 8 | 12 | 18 | 6–24 |
| 테이프(높이) | 14 | 22 | 32 | 12–48 |
| 지우개(지름) | 8 | 16 | 32 | 6–40 |

### 2-8. 더 보기 줄 (⋯)

- ⋯를 누르면 칸 아래 8px에 두 번째 알약이 나온다(칸이 세로면 옆). 같은 재질이고, 160ms opacity + translate 6px.
- 아이콘 8개(이름은 툴팁):
  - 찾기(⌘K)
  - 도형(한 획)
  - 글 상자
  - 사진
  - 쪽 서랍
  - 손가락으로 쓰기 ◐
  - 긁어 지우기 ◐
  - 내보내기
- ◐는 켜고 끄는 아이콘이다. 켜짐은 아이콘 아래 4px 점으로 보인다.
- 다시 ⋯를 누르거나 종이를 누르면 닫힌다. 한 번 도구를 고르면 바로 닫힌다.
- **터치 기기에서 ⌘K로 가는 길은 여기다**(찾기 아이콘).

| 펜 호버(되는 기기) | 펜 끝 자리에 지금 색·굵기의 점(불투명도 .5)을 보인다. 지우개는 원 테두리. 지연 0 |

## 3. 둥근 메뉴

### 3-1. 여는 법

| 어디서 | 손 | 조건 | 무엇이 |
|---|---|---|---|
| 종이 **빈 곳** | 손가락 | 450ms | 빈 곳 메뉴 6칸 |
| 종이 **빈 곳** | 펜 | 600ms + 고리 예고 | 빈 곳 메뉴 6칸 |
| 종이 **빈 곳** | 마우스 | 오른쪽 클릭(즉시) · 왼쪽 600ms | 빈 곳 메뉴 6칸 |
| 잉크 · 사진 · 글 상자 · 테이프 위 | 손가락 · 마우스 오른쪽 | 450ms · 즉시 | 메뉴가 아니라 **고르기**(24pt 안에 이어진 획 묶음 또는 그 물건) → 선택 칸(6장) |
| 잉크 위 | 펜 | — | 아무것도 하지 않는다(펜을 종이에 대고 생각하는 일이 많다) |
| 사진 · 글 상자 · 테이프 위 | 펜 | 600ms | 고르기 → 선택 칸(테이프 공부 중 펜으로 '헷갈림'을 표시하는 길, 7-6) |
| 쪽 썸네일(서랍) | 손가락 · 펜 | 650ms(300ms에 들림, 5-3) | 쪽 메뉴 4칸 |
| 테이프 칩 | 손가락 · 펜 | 450 / 600ms | 테이프 메뉴 4칸(7-5) |
| 새 노트 버튼 | 손가락 · 펜 | 450 / 600ms | 노트 메뉴 3칸(1-1) |

- **펜 고리 예고:**
  - 300ms부터 펜 끝 둘레에 고리가 차오른다: 반지름 10 → 16px, 선 1.5px `--text-3`, 불투명도 0 → 60%, 0° → 360°.
  - 600ms에 다 차면 메뉴가 뜬다.
  - 그 전에 4px 넘게 움직이거나 떼면 고리는 80ms에 사라지고 아무 일도 없다.
- **찍힌 점 처리:** 펜이 닿는 순간 찍힌 점(획)은 메뉴가 뜨면 지운다. 되돌리기 기록에도 남기지 않는다. 메뉴 전에 떼면 그 점은 진짜 점이니 남긴다.

| 나타남 · 사라짐 | scale .86 → 1 + opacity, 160ms `--ease-out` · 100ms |

### 3-3. 빈 곳 메뉴 6칸 (12시부터 시계 방향)

| 자리 | 칸 | 하는 일 |
|---|---|---|
| 12시 | **붙이기** | **누른 점**에 붙인다. 앱 안 클립보드(획·물건)가 있으면 그것을 먼저 쓰고, 없으면 시스템 클립보드를 읽는다(그림 → 사진, 글 → 글 상자). Safari는 이때 '붙여넣기' 확인 말풍선을 띄울 수 있다. 둘 다 비었으면 메뉴가 닫히고 확인 칩이 흔들린다(4-2의 '벽' 피드백) |
| 2시 | **글 상자** | 누른 점에 글 상자를 만들고 키보드를 연다 |
| 4시 | **사진** | 파일 고르기(폰은 사진·카메라). 고른 사진을 누른 점에 넣는다 |
| 6시 | **쪽 추가** | 지금 쪽 뒤에 같은 틀의 새 쪽을 넣고, 그 쪽 맨 위로 420ms `--ease-in-out` 스크롤한다 |
| 8시 | **쪽 틀** | 누른 자리 옆에 틀 그림 5개 줄(40×56). 고르면 지금 쪽 틀을 바꾼다. 줄 끝 '모든 쪽' 토글(겹친 쪽 아이콘) |
| 10시 | **도형** | **다음 한 획**을 멈추지 않아도 도형으로 바꾼다(한 번만). 그동안 구슬·지금 도구 아이콘에 작은 삼각형 표시가 붙는다 |

- **배치 이유:** 위는 가장 잦은 붙이기, 아래는 '아래로 쪽 늘리기', 오른쪽은 넣기(글·사진), 왼쪽은 모양(틀·도형)이다.

### 3-4. 고르기

| 방법 | 규칙 |
|---|---|
| **끌어 놓기** | 누른 채 움직인다. 손끝이 가운데 원 밖에 있는 동안, 고리 가운데에서 본 손끝 방향의 칸이 밝아진다(80ms). 떼면 그 칸을 고른다 |
| **튕기기** | 메뉴가 뜬 뒤 그 방향으로 빠르게 튕겨도 된다. 거리 ≥ 28px면 충분하다. 바깥 반지름을 넘어 놓아도 방향으로 고른다 |
| **눌러 고르기** | 움직이지 않고 떼면 메뉴가 그대로 남는다(고정). 칸을 누르면 고른다 |
| 고른 순간 | 고른 칸 scale 1.06 → 1(120ms), 메뉴는 opacity 0(100ms) |
| 이름 | 고정 상태이거나 끄는 중에 한 칸에서 600ms 머물면, 그 칸 바깥 8px에 이름 1줄(13px `--text-1`, `--surface-3` 바탕)이 뜬다 |

### 3-5. 취소

- 손끝을 가운데 원 안으로 되돌려 놓고 뗀다.
- 고정 상태에서 가운데 원이나 메뉴 바깥을 누른다.
- Esc · 두 손가락 탭(되돌리기는 안 함) · 다른 손가락이 닿음 · 화면 회전·크기 바뀜.
- 취소 모션: scale 1 → .92 + opacity 0, 100ms.

### 4-2. 되돌리기

- **대상:**
  - 획 더하기·지우기
  - 물건 더하기·옮기기·크기·회전·지우기·글 바꾸기
  - 색·굵기 바꾸기(고른 것)
  - 쪽 추가·지우기·순서·틀
- **넣지 않는 것:** 테이프 걷기·붙이기(공부 동작이지 편집이 아니다), 확대·이동, 도구 바꾸기, 도구 칸 자리.
- **한도:** 노트를 연 동안 200단계. 닫으면 비운다.
- **모션:**
  - 되돌린 획은 120ms 동안 opacity 1 → 0이 된다(지운 것을 되살리면 0 → 1).
  - 바뀐 곳이 화면 밖이거나 다른 쪽이면, 먼저 320ms `--ease-in-out`로 그곳까지 스크롤한 뒤 같은 모션을 한다.
- **확인 칩:**
  - 도구 칸 옆에 작은 칩을 띄운다(칸이 위면 그 아래 12px, 아래면 그 위 12px, 옆이면 화면 위 가운데).
  - 칩에는 ↶(다시하기 ↷) 16px를 두고, 연속이면 모노 숫자 "3"을 붙인다.
  - 600ms 보인 뒤 200ms에 사라진다. 글자는 없다.
  - 되돌릴 것이 없으면 칩이 좌우로 3px씩 두 번 흔들린다(160ms).

### 4-3. 긁어 지우기 판정

- 펜 도구(볼펜·만년필·연필)의 획이 **끝났을 때만** 판정한다. 형광펜·테이프에서는 하지 않는다.
- 다음 네 가지를 **모두** 만족하면 긁기로 본다:
  1. **뒤집힘:** 획의 긴 축을 따라 진행 방향이 4번 이상 뒤집힌다(뒤집힘 사이 폭 ≥ 6pt).
  2. **촘촘함:** 경로 길이 ≥ 바운딩 상자 대각선 × 3.
  3. **빠름:** 1,500ms 이하.
  4. **겹침:** 긁은 획의 볼록 껍질(+4pt 여유) 안에 점의 60% 이상이 드는 기존 획이 1개 이상 있다.
- **맞으면:** 긁은 획과 겹친 획을 함께 지운다(되돌리기 1단계). 둘 다 140ms에 opacity 0이 된다.
- **안 맞으면:** 보통 획으로 남는다. 빈 곳에 친 빗금·색칠은 4번 조건 때문에 지워지지 않는다.
- 끄기: 더 보기 줄의 ◐, ⌘K '긁어 지우기'.

### 4-4. 펜만 쓰기 · 손바닥

- **기본은 손가락 쓰기 켬**이다(펜이 없는 사람도 바로 쓸 수 있게).
- `pointerType === 'pen'`이 한 번이라도 오면 **자동으로 펜만 쓰기**로 바꾸고 이 기기에 기억한다(`meta['ink.fingerDraw'] = false`).
  - 바뀌는 순간 구슬 옆에 손가락 아이콘이 나타나고, 사선이 그어지며 1.2초에 흐려진다(글자 없음).
- **펜만 쓰기:** 손가락은 이동·확대·탭 제스처·고르기만 한다.
- **손가락 쓰기:** 한 손가락은 쓰기, 두 손가락은 이동·확대다. 탭 제스처는 같다.
- 손바닥 판정 수치는 0-2에 있다.

| 썸네일 그림 | 쪽을 저장할 때 240px 폭 그림을 다시 만든다(쉴 때, 디바운스 1초) |

### 5-3. 동작

| 동작 | 규칙 |
|---|---|
| 썸네일 누르기 | 그 쪽으로 420ms `--ease-in-out` 스크롤한다. 태블릿·데스크톱은 서랍이 열린 채 있고, 폰은 닫힌다 |
| **순서 끌기** | 손가락은 300ms 누르면 썸네일이 들린다(scale 1.05, `--shadow-3`). 마우스는 바로 끈다. 다른 썸네일은 180ms `--ease-out`으로 비킨다. 놓으면 `index` = 앞뒤 값의 가운데(실수). 서랍 위·아래 48px 안에서는 자동 스크롤(최대 600px/s) |
| 쪽 메뉴 | 들린 채 움직이지 않고 650ms가 되면 둥근 메뉴 4칸: **12시 복제 · 3시 뒤에 새 쪽 · 6시 지우기 · 9시 틀** |
| 지우기 | 확인 없이 소프트 삭제(`deletedAt`)한다. 되돌리기 1단계다. 썸네일은 높이를 접으며 200ms에 사라진다 |
| 틀 바꾸기 | 틀 그림 5개 줄(40×56). 지금 틀은 금 테두리. 끝의 '모든 쪽' 토글. 이름은 툴팁으로만 |

### 5-4. PDF 가져오기 · 내보내기

- **가져오기:**
  - 머리 아이콘(또는 끌어 놓기·⌘K)으로 파일을 고르면 **지금 쪽 뒤에** PDF 쪽들을 끼운다.
  - 진행: 서랍 위 가장자리에 2px 금 선이 쪽 수만큼 왼쪽에서 오른쪽으로 찬다. 썸네일이 하나씩 120ms 페이드로 들어온다. 글자는 없다.
  - 아직 그리지 않은 PDF 쪽: 흰 쪽 위 가장자리에 2px 금빛 흐름(1.2초 왕복)을 보인다.
  - 200쪽이 넘으면: 처음 20쪽을 먼저 그리고, 나머지는 쉴 때 이어서 그린다.
  - 실패: 서랍 머리 아래에 `--danger` 한 문장 "이 PDF는 열 수 없어요."를 쓴다. 오류만 글로 쓴다.
- **내보내기:**
  - 머리 아이콘을 누르면 작은 팝오버가 열린다. 아이콘 2개 [PDF 전체] [이 쪽 그림(PNG)]와 토글 1개 [테이프: **뺌**(기본) / 포함]이 있다.
  - 고르면 파일을 만들고, 내려받기 또는 공유 시트(iOS)로 넘긴다.
  - 만드는 동안 그 아이콘 둘레에 1.5px 금 호가 진행만큼 찬다.
  - 테이프 뺌 = 테이프를 그리지 않는다(내용이 보인다). 포함 = 붙어 있는 테이프만 그린다.
  - 종이는 언제나 흰 종이, 잉크는 저장 색이다(1-6).

## 6. 선택 칸 (올가미 뒤)

### 6-1. 고른 모양

- **고른 상자:** 1px 점선(4 · 4) `--text-3`, 고른 것 둘레 여백 8px.
- **모서리 손잡이 4개:** 지름 10px, `--text-1` 면 + 1px 종이색 테두리, 누르는 영역 32px.
- **회전 손잡이:** 위 가운데에서 24px 위에 지름 10px 원, 가는 선으로 잇는다.
- **옮기기:** 상자 안을 끈다. **크기:** 모서리를 끈다(비율 유지가 기본). **회전:** 15°마다 자석(±3°).
- 고른 획의 색은 바꾸지 않는다(덮는 색 없음).

### 6-2. 선택 칸

- 높이 44(마우스 36), 버튼 40(32), 아이콘 20px. 재질은 도구 칸과 같다(blur 없음).

| # | 잉크를 골랐을 때 | 사진·글 상자를 골랐을 때 | 테이프를 골랐을 때 |
|---|---|---|---|
| 1 | **색**(고른 것의 색 점. 섞였으면 반반 점) → 펜 12색(형광 획이면 형광 6색) | 글 상자: 글 색 / 사진: 없음 | **헷갈림** ●(결정 2) |
| 2 | **가리기**(테이프 아이콘) → 고른 상자 위에 테이프를 덮는다(지금 테이프 색, 여백 4pt). 고름이 풀리고 새 테이프가 붙은 채 남는다 | 가리기 | 색(테이프 6색) |
| 3 | **복사** → 앱 안 클립보드. 되면 시스템 클립보드에 PNG도 넣는다. 아이콘이 300ms ✓가 된다 | 복사 | 걷기·붙이기 |
| 4 | **복제** → +16pt, +16pt 자리에 복사본. 복사본을 고른 상태로 둔다 | 복제 | 복제 |
| 5 | **지우기** → 되돌리기 1단계 | 지우기 | 지우기 |
| 6 | **⋯** → 잘라내기 · 그림으로 저장(PNG) · (M4) 카드로 | ⋯ → 잘라내기 · 맨 앞으로 · 맨 뒤로 | — |

### 6-3. 자리 규칙

1. **기본:** 고른 상자 위, 가로 가운데, 틈 12px.
2. 위에 자리가 없으면(상자 위 끝 − 56px이 화면 위 안전선 밖이거나 도구 칸과 겹침) **상자 아래** 12px.
3. 둘 다 안 되면(상자가 화면보다 큼) 화면 위 안전선 아래 12px에 붙인다. 도구 칸이 위에 있으면 그 아래 8px.
4. 가로는 화면 가장자리에서 12px 안으로 자른다.
5. 끄는 동안 칸은 opacity 0(80ms). 놓고 120ms 뒤 새 자리에서 opacity 1(140ms).
6. 확대·이동 중에는 같은 프레임에 상자를 따라간다.

- **풀기:** 상자 밖 누르기(그 누름은 점을 찍지 않는다), Esc, 다른 도구 고르기. 올가미 도구일 때 상자 밖에서 끌면 새 올가미가 시작된다.

## 7. 가리개 테이프

### 7-1. 붙이기

- 테이프 도구로 긋면, 획의 긴 축을 따라 사각형 테이프가 생긴다.
  - 높이 = 테이프 굵기(14 · 22 · 32pt), 길이 = 획 양 끝 + 앞뒤 4pt.
  - 수평에서 ±8° 안이면 수평으로 붙인다. 그 밖이면 그 각도(`rot`)를 쓴다.
  - 길이가 높이보다 짧으면 만들지 않는다.
- 긋는 동안: 불투명도 60% 테이프가 손을 따라 늘어난다. 떼면 100%가 되고 양 끝이 찢긴 모양으로 바뀐다(80ms).
- 올가미 → 선택 칸 **가리기**로도 붙인다(6-2).
- 테이프는 쪽에서 가장 위 층이다(`z` 최대). 데이터는 `PageItem { kind: 'tape', hidden }`.

### 7-2. 모양

| 부분 | 밤 종이 | 낮 · 흰 종이 |
|---|---|---|
| 면 | 테이프 색(밤 짝) 100% | 테이프 색 100% |
| 결 | 사선 섬유 `repeating-linear-gradient(-35deg, rgba(255,255,255,.035) 0 1px, transparent 1px 5px)` | 같은 무늬 `rgba(0,0,0,.035)` |
| 양 끝 | 찢긴 지그재그: 진폭 1.2pt, 주기 3.5pt. 모양은 테이프 id 해시로 조금씩 다르다 | 같음 |
| 그림자 | `0 1px 0 rgba(0,0,0,.35)` + 위 안쪽 1px 빛 `rgba(255,255,255,.06)` | `0 1px 2px rgba(30,25,15,.12)` |
| **걷힌 뒤** | 면 0. 테두리 1px 점선(3 · 3) 테이프 색 45%, 양 끝 지그재그 선만 남는다 | 같음, 35% |
| 헷갈림(결정 2) | 오른쪽 끝 안쪽 4pt에 지름 4pt 점 `--seal` | `#A8402C` |

### 7-3. 걷히는 모션

| 바뀜 | 모션 |
|---|---|
| 붙음 → **걷힘** | 누른 점에서 가까운 끝부터 반대 끝으로 걷힌다. 260ms `--ease-out`으로 `clip-path`가 열린다. 걷히는 가장자리에는 폭 4pt의 '들린 끝'(밝기 +8%, 그림자 `0 2px 6px rgba(0,0,0,.35)`)이 따라간다. 끝나면 걷힌 모양(점선)이 120ms에 나타난다 |
| 별빛 | 누른 점에서 별빛 금 `#F3D29A`(낮 `#7A5714`) 점 3개(지름 1.5px)가 6–10px 퍼지며 400ms에 사라진다. 각도는 테이프 id 해시. **하늘은 깨우지 않는다**(종이 층) |
| 걷힘 → **붙음** | 누른 끝에서 반대 끝으로 덮인다. 180ms `--ease-in-out`, 별빛 없음 |
| 동작 줄이기 | opacity 120ms만 |

### 7-4. 누르기 판정

- 테이프 위 **누르기**(이동 < 6px, 길게 누르기 시간 전에 뗌) = 걷기·붙이기. 펜·손가락·마우스 모두 된다. 길게 누르면 고르기다(3-1).
  - 예외: 도구가 올가미면 고르기, 지우개면 지우기다.
- 펜으로 테이프 위를 **끌면** 쓰기다(테이프 위에 실마리를 쓸 수 있다).
- 걷힌 테이프 자리(점선 안)를 누르면 다시 붙는다. 그 자리에 점을 찍고 싶으면 끌어서 쓴다.

### 7-5. 모두 걷기 · 다시 붙이기

| | 값 |
|---|---|
| **테이프 칩** | 테이프가 1개 이상인 쪽에만 있다. 쪽 오른쪽 위 모서리 바깥 8px(종이 옆 여백 ≥ 56px일 때) 또는 안쪽 8px(태블릿 세로·폰). 높이 28, 안쪽 여백 0 10, 모서리 14, `--surface-2` 92%, 테이프 아이콘 16px + 모노 11px **"3/7"**(걷힌 수 / 전체) |
| 칩 누르기 | 하나라도 붙어 있으면 **이 쪽 모두 걷기**, 다 걷혔으면 **모두 다시 붙이기** |
| 모두 걷기 모션 | 읽는 순서(위 → 아래, 같은 줄이면 왼 → 오)로 30ms 간격, 하나당 200ms(7-3 모션). 별빛은 마지막 하나만 |
| 모두 붙이기 모션 | 같은 순서로 30ms 간격, 하나당 160ms |
| 칩 길게 누르기 | 둥근 메뉴 4칸: **12시 노트 전체 걷기 · 6시 노트 전체 붙이기 · 3시 헷갈린 것만 붙이기**(결정 2. 없으면 흐림) **· 9시 이 쪽 테이프 모두 지우기**(되돌리기 1단계) |
| 한 쪽 다 떠올림 | 하나씩 눌러 모두 걷으면 칩 숫자가 금 `--accent`로 240ms에 바뀐다(10장 K4) |
| 키 · ⌘K | `⇧T` 이 쪽, `⌥⇧T` 노트 전체. ⌘K '테이프 모두 걷기 / 다시 붙이기(이 쪽 · 노트)' · '헷갈린 테이프만 붙이기' |

### 7-6. 떠올리기 공부와 잇기

1. 칩을 눌러 모두 붙인다.
2. 하나씩 떠올리고, 눌러 걷어 확인한다.
3. 틀렸으면 그 테이프를 **길게 눌러 고르고 → 선택 칸 1번 '헷갈림'**을 누른다. 인주 점이 생긴다. 다시 누르면 지운다.
4. 칩을 길게 눌러 '헷갈린 것만 붙이기'로 다시 연습한다.

- 테이프 걷기·붙이기는 되돌리기 기록에 넣지 않는다(4-2).
- 헷갈림 표시는 `PageItem.flag`가 필요하다(스키마, 결정 2). '나중'으로 정하면 3·4단계는 M4로 미룬다.
- **M4 연결:** 테이프 하나 = 복습 카드 하나.
  - 앞면 = 테이프가 붙은 쪽 부분 그림(테이프 둘레 + 위아래 맥락 48pt).
  - 뒷면 = 걷힌 그림.
  - 헷갈림 표시는 첫 평가 '다시'로 들어간다.

## 8. 메모 강화

### 8-1. 메모 칸에 펜을 대면 잉크 칸이 된다

**세 가지 상태:**

| 상태 | 언제 | 모양 |
|---|---|---|
| 글 | `n` · 손가락/마우스로 ＋ · ⌘K(M2 그대로) | 입력 줄에 포커스, 키보드가 올라온다 |
| **펜 대기** | ＋를 **펜으로** 누름 | 같은 칸. 포커스를 주지 않아서 키보드가 없다. 자리표시 대신 입력 줄 왼쪽에 펜 아이콘 16px `--text-3`. 이 상태에서 키보드로 치기 시작하면 바로 글 상태가 된다 |
| **잉크** | 펜이 칸에 닿음 | 아래 전환 |

**펜이 닿으면 잉크가 되는 곳:**
- 입력 줄이 **비어 있으면** 칸 어디든 잉크가 된다.
  - 칸 위에 투명한 잉크 층을 둔다. 펜이 아닌 누름은 그 층이 받아 입력 줄에 `focus()`를 넘긴다.
  - 그래서 iPad Scribble이 끼어들지 않는다.
- 입력 줄에 **글이 있으면** 입력 줄 위는 Scribble(손글씨 → 글자)로 남기고, 그 밖의 빈 곳만 잉크가 된다.

**전환(글 · 펜 대기 → 잉크):**

| t (ms) | 일 |
|---|---|
| 0 | 같은 pointerdown으로 잉크가 시작된다(**첫 점을 잃지 않는다**). 잉크 캔버스는 처음부터 커진 칸 크기로 깔려 있고 칸 밖은 잘려 있다 |
| 0–200 | 칸이 **위로** 자란다. 태블릿 116 → **260px**, 폰 116 → 240px. `--ease-out`. 칸 아래 끝이 고정이라 **펜 아래 그림은 움직이지 않는다**. 빈 입력 줄과 자리표시는 100ms에 사라진다. 글이 있었으면 그 줄이 커진 칸 맨 위로 FLIP(200ms)해 메모의 첫 줄이 된다 |
| 키보드가 올라와 있었다면 | 입력 포커스를 풀되 **칸 자리는 펜을 뗄 때까지 그대로 둔다.** 첫 획이 끝나면 키보드와 함께 칸이 제자리(아래 32px)로 240ms에 내려간다 |

**잉크 칸 안:**
- 캔버스 = 칸 − 아래 줄 40px.
- 펜(1번 색, 보통 굵기)만 쓴다. 긁어 지우기와 두 손가락 탭 되돌리기는 된다. 도구 칸은 없다.
- **아래 줄:** 왼쪽은 과목 칩(M2 그대로). 오른쪽은 **Aa**(맨 위에 글 줄을 붙이고 포커스)와, 잉크가 있으면 나타나는 **↑ 저장**(금빛 원 32px).
- **저장:** ↑ · ⌘Enter. 칸이 닫히고 80ms 뒤 별가루 D1(M2 그대로).
- **닫기(저장 안 함):** Esc · 칸 밖 누르기. 잉크도 초안으로 남는다(M2의 초안 1개 규칙).

### 8-2. 메모 종류 입구: 아이콘 하나에서 펼쳐짐

```
 [ 생각 하나                                    (＋) ]
                       ↓ ＋ 누르기
 [ 생각 하나            (손글씨)(체크)(사진)(음성)(×) ]
```

- M2의 사진 버튼 자리(입력 줄 오른쪽 끝, 36px)를 **＋** 하나로 바꾼다.
- ＋를 누르면:
  - ＋가 45° 돌아 ×가 된다.
  - 아이콘 4개(36px, 사이 4px)가 ＋ 밑에서 왼쪽으로 미끄러져 나온다. 30ms 간격, 160ms `--ease-out`.
- 하나를 고르거나 ×를 누르면 120ms에 접힌다.

| 아이콘 | 하는 일 |
|---|---|
| 손글씨 | 잉크 상태로 간다(손가락·마우스로도 쓴다. 폰은 이 길뿐이다) |
| 체크 | 체크리스트 상태(8-3). 입력 줄 맨 앞에서 `[] `를 치는 것과 같다(M2 편집기와 같은 단축) |
| 사진 | M2 사진 그대로 |
| 음성 | 녹음 시작(8-4). **보안 주소가 아니거나**(`!isSecureContext`) MediaRecorder·getUserMedia가 없으면 이 아이콘은 **숨긴다**(흐리게 두지 않는다) |

### 8-3. 체크리스트 메모

- 줄마다 16px 네모(M2 3-3의 체크 모양) + 글.
- **키:**
  - Enter = 새 항목.
  - **빈 항목에서 Enter = 저장**(빈 항목은 버린다).
  - ⌘Enter = 언제나 저장.
  - 빈 항목에서 Backspace = 그 항목을 지우고 윗줄 끝으로.
- 칸은 6줄까지 늘어나고, 그 뒤로는 칸 안에서 스크롤한다.
- **별가루함 줄:** 처음 2항목 + 모노 "+3".
- **할 일로:** 체크 안 된 항목마다 과제 1개(마감 없음). **노트로:** 체크 블록 그대로.

### 8-4. 음성 메모

| 단계 | 모양 |
|---|---|
| 녹음 중 | 입력 줄이 파형 줄로 바뀐다. 금빛 막대(폭 2px, 사이 2px, 최고 24px, 최근 1.6초가 오른쪽에서 왼쪽으로 흐름) + 모노 13px "0:12" `--text-2` + 오른쪽 정지 ■(36px) |
| 멈춘 뒤 | ▶(36) + 전체를 48막대로 줄인 고정 파형 + "0:42". ↑ 저장이 나타난다. Enter 저장 |
| 상한 | 10분. 9:30부터 시간 글자가 `--accent`. 10:00이면 저절로 멈춘다(저장은 사용자가 ↑로) |
| 저장 | Blob(`audio/webm` 또는 Safari `audio/mp4`) → Asset. 메모 `kind: 'voice'`, `durationMs` |
| 별가루함 줄 | ▶ + 24막대 파형 + "0:42". 누르면 그 자리에서 재생하고, 파형이 금으로 차오른다 |
| 할 일로 · 노트로 | 할 일로: 제목 "음성 메모 0:42" + 첨부. 노트로: 글 노트 끝에 '소리 칩'(▶ + 길이)을 붙인다. 앱 A의 새 블록이 필요하다(결정 6) |

### 8-5. 고정

- 별가루함 줄의 동작에 **고정**(핀 아이콘)을 더한다. 키 `P`.
- **고정된 줄:**
  - 목록 맨 위에 묶인다(묶음 아래 1px `--border` 선).
  - 줄 오른쪽 위에 핀 12px `--text-3`.
- **하늘:**
  - 고정된 별가루 점은 **떠돌지 않는다**(D2 표류 0). 밝기는 45 → 50%.
  - 고정하는 순간 그 점이 V11(+40%, 300ms)로 반짝인다(10장 K6).
- 고정해도 '별가루 n'에 센다. 개수 상한은 없다.

### 8-6. 별가루함에서 여러 개 고르기

| | 값 |
|---|---|
| 들어가기 | 줄 길게 누르기(450ms). 그 줄을 고른 채 시작한다. 데스크톱은 ⌘-클릭·⇧-클릭, 키 `X`(포커스 줄 고르기) |
| 모양 | 모든 줄 왼쪽에 20px 원이 160ms에 미끄러져 들어온다(줄 내용은 28px 오른쪽으로). 고르면 원이 금 면 + 어두운 ✓ |
| **끌어 고르기** | 길게 누른 손가락을 떼지 않고 위아래로 끌면, 지나간 줄이 모두 골라진다. 위아래 끝 48px에서는 자동 스크롤 |
| 동작 칸 | 아래에 떠 있는 알약(도구 칸 재질, 높이 48): 모노 숫자 "3" + [노트로] [할 일로] [과목] [고정] [보관]. 아이콘만 |

| 노트로(여러 개) | 과목별로 묶는다. 과목마다 오늘 수업 노트 끝(있으면) 또는 새 노트 "메모 10.17"에 만든 시각 순서로 붙인다. 손글씨 메모는 받는 노트가 필기면 획 그대로(마지막 쪽 아래 빈 곳, 없으면 새 쪽 맨 위), 글 노트면 그림(PNG 2배)으로 |

### 8-7. 과목별 보기 · 순서 · 메모 안 찾기 (별가루함 머리)

- 머리 줄 오른쪽에 아이콘 3개(36px): **[과목] [순서] [찾기]**.
- **과목:** 머리 아래로 과목 줄(점 12px + 과목 이름 13px, 가로 스크롤)이 펼쳐진다. 하나를 고르면 그 과목만 보인다. 다시 누르면 전체.
- **순서:** 새 것 위(기본) ↔ 오래된 것 위. 아이콘이 180ms에 위아래로 뒤집힌다.
- **찾기:** 머리의 명사구 자리에 찾기 칸(36px, 돋보기)이 들어온다. 치는 대로 그 자리에서 거른다(검색 색인 그대로). Esc로 닫는다.
- **줄 모양:**

| 종류 | 줄 모양 |
|---|---|
| 글 · 사진 | M2 그대로 |
| 체크리스트 | 처음 2항목(12px 네모) + "+3" |
| 손글씨 | 잉크를 높이 40px 띠 그림으로(밤 변환 색) |
| 음성 | ▶ + 파형 + 길이 |

## 9. '글 줄이기'와 함께 가는 기능 노출 원칙

### 9-1. 네 층

| 층 | 무엇 | 잉크 화면에서 |
|---|---|---|
| **상주** | 늘 보인다 | ‹ 뒤로, 도구 칸(쓰는 동안은 구슬). **이 둘뿐이다** |
| **상황** | 그때만 보인다 | 선택 칸(고르면), 테이프 칩(테이프 있는 쪽), 쪽 번호(넘길 때), 펜 호버 점, 되돌리기 칩 |
| **부름** | 손이 부른다 | 길게 누르기(둥근 메뉴 · 도구 옵션 · 툴팁), 제스처(되돌리기 · 서랍 · 확대), 도구 칸 ⋯, 키 |
| **전부** | 언제나 닿는다 | ⌘K(잉크 명령 전부 + 키 표시), '제스처 보기' 시트 |

- **규칙 1:** '상황'과 '부름'에 있는 기능은 모두 '전부'(⌘K)에도 있다(0-4).
- **규칙 2:** 한 기능의 입구는 둘 이상이다. 예: 쪽 추가 = 둥근 메뉴 6시 · 서랍 끝 ＋ · 쪽 메뉴 3시 · ⌘K.
- **규칙 3:** '상주'와 '상황' 층에는 글이 없다. 글은 손이 부를 때 이름 1줄로만 나온다(툴팁 · 팝오버 첫 줄 · 둥근 메뉴 머무름). 그 밖의 글은 **오류 한 문장**과 **쪽 서랍 머리의 노트 제목**뿐이다.
- **규칙 4:** 이 기기에서 안 되는 기능은 흐리게 두지 않고 **숨긴다**(예: 보안 주소가 아닐 때 음성). 지금만 고를 수 없는 것은 30%로 흐린다(예: 쪽이 1장일 때의 '쪽 지우기').
- **규칙 5 (다크 패턴 없음):**
  - 안내는 한 번만 보이고, 누르면 바로 사라진다.
  - 자동으로 바뀌는 것(펜만 쓰기, 긁어 지우기, 펜 길게 누르기 메뉴, 도구 칸 펴짐)은 모두 ⌘K에서 끌 수 있다.
  - 지우기는 모두 되돌릴 수 있다.
  - 기본값은 사용자에게 유리하게 둔다(예: 내보내기는 '테이프 뺌').

### 9-2. 툴팁

| | 데스크톱(`hover: hover`, `pointer: fine`) | 터치 · 펜 |
|---|---|---|
| 띄우기 | 올리고 **600ms** | **길게 누르기 450ms**(펜 600ms). 누르는 동안 보인다 |
| 연달아 | 툴팁이 한 번 뜬 뒤 800ms 안에 옆 버튼으로 가면 **바로**(0ms) 뜬다 | — |
| 숨기기 | 벗어나면 0ms, 누르면 0ms | 떼고 1,200ms 뒤 |
| 동작 | — | 툴팁을 띄운 누름은 **버튼을 실행하지 않는다** |
| 자리 | 버튼 위 8px(위가 막히면 아래) | 손가락 위 44px, 펜 위 28px(가리지 않게) |
| 내용 | 이름 13px `--text-1` + 단축키 모노 11px `--text-3`. 한 줄이고 문장은 쓰지 않는다 | 같음 |
| 면 | `--surface-3`, 모서리 8, 안쪽 6 · 10 | 같음 |

- 길게 누르기에 자기 동작이 있는 것(도구 → 옵션, 색 점 → 색 팝오버)은 그 팝오버 첫 줄의 이름이 툴팁을 대신한다.

## 10. 하늘과 연결

- **쓰는 동안 하늘은 쉼이다.**
  - `useFieldPause(true, 'ink')`에 아래 K0의 자리를 더한다.
  - 종이는 불투명하고, 여백에는 멈춘 하늘이 노출 0.5로 보인다.
  - 잉크 입력은 `kick()`을 부르지 않는다(0-5).
- 쓰는 동안 일어난 하늘 사건(새 노트 별 등)은 최종 상태만 기록해 둔다. 닫을 때 볼 수 있다(M1 0-2 규칙 3).

## 11. 폰(390)과 데스크톱(마우스)

## 12. 꼭 알 것 · 리더 결정

### 개발자가 꼭 알아야 할 것 5가지

1. **판정 숫자는 한 파일에 둔다**(0-2): 6px / 250ms, 길게 누르기 손가락 450ms · 펜 600ms, 두 손가락 탭 80ms. **펜 길게 누르기로 메뉴가 뜨면 찍힌 점을 지우고**, 되돌리기 기록에도 남기지 않는다. 테이프 걷기도 되돌리기에 넣지 않는다.
2. **쓰는 동안 하늘은 쉼이고, 잉크 입력은 `kick()`을 부르지 않는다.** 잉크 화면에 떠 있는 것은 blur 없이 `--surface-2` 96%로 칠하고, transform · opacity · clip-path로만 움직인다. 도구 칸 접힘은 첫 잉크 다음 rAF에 시작한다.
3. **잉크 색은 흰 종이 기준으로 저장한다.** 밤 종이에서만 짝 색(1-6 표, 그 밖은 OKLCH 식)으로 바꿔 그린다. 내보내기는 저장 색 + 흰 종이 그대로라 인쇄해도 맞다.
4. **명령 하나, 입구 여럿**(0-4): `INK_COMMANDS`에 등록하면 버튼·제스처·둥근 메뉴·키·⌘K가 같은 id를 부른다. 등록된 id가 ⌘K에 모두 나오는지 시험한다. 이것이 '글을 빼도 기능을 잃지 않는다'의 보증이다.
5. **자리가 흔들리지 않게 한다:** 도구 버튼 5개는 움직이지 않는다(칸은 도구 쪽 끝에 고정). 메모 칸은 위로 자란다(펜 아래 그림은 고정). 전환 중 펜이 닿으면 최종 상태로 건너뛰고 첫 점을 살린다.

### 리더 결정이 필요한 것

1. **하늘 API 3개(추가만):**
   - `useSkyPaper(open)`: 노트 장소 'ink' 자리, 띠가 화면 밖으로, 노출 0.5, 쉼.
   - `inkToStar(noteId, { pages })`: 닫을 때의 반짝임 + 지도 보류 재생.
   - `pinDust(id, on)`: 고정된 별가루.
2. **스키마 v4:**
   - `Memo`: `kind?: 'text' | 'check' | 'photo' | 'ink' | 'voice'`, `items?: { text, done }[]`, `pinned?: boolean`, `pageId?: string`(손글씨 = `noteId: 'memo:<id>'`인 Page 한 장), `durationMs?: number`.
   - `PageItem`(테이프): `flag?: 'unsure' | null`.
   - 헷갈림 표시를 M4로 미루면 `flag`는 빼도 된다.
3. **펜 길게 누르기 = 둥근 메뉴**를 기본으로 켤지 정해야 한다(600ms + 고리 예고).
   - 위험: 펜을 종이에 대고 생각하는 학생에게 메뉴가 잘못 뜰 수 있다.
   - 이점: 손가락을 쓰지 않는 사람도 닿는다.
   - 제안: 켬. ⌘K에 끄기를 둔다.
4. **입력한 손이 정한다:** 새 노트·＋를 펜으로 누르면 필기 노트·손글씨 메모, 손가락·키보드면 글을 연다. 이것을 기본으로 할지 정해야 한다(길게 누르면 언제나 직접 고를 수 있다).
5. **도구 칸 기본 자리 = 위 가운데**(과목 알약이 도구 칸으로 모양을 바꿈). 폰은 아래 가운데다. 굿노트와 같은 위쪽이 손바닥과 덜 겹친다.
6. **음성 메모 '노트로'는 둘 중 하나로 정해야 한다:**
   - (a) 글 노트에 '소리 칩' 블록을 만든다(앱 A가 TipTap 노드 1개를 더함).
   - (b) M3에서는 음성을 '할 일로 · 보관'만 한다.
   - 제안: (a).
