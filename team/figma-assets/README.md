## 대체·결정 기록

- 글꼴: Hahmlet Light, Noto Sans KR, JetBrains Mono Light는 그대로 썼다. **Fraunces는 Figma에 ExtraLight(200)가 없어서 타이머에 Light(300)를 썼다**(opsz 축은 지정하지 않음).
- 메타 줄의 한글은 JetBrains Mono에 한글 글자가 없어서 Noto Sans KR Regular로 따로 지정했다.
- F31(M0 '전' 화면)은 사용자가 보고 있는 127.0.0.1:5173 탭을 건드리지 않으려고 캡처하지 않았다. 대신 M0 문구와 동심 등고선·인주 고리를 **편집 가능한 레이어로 다시 그렸다**.
- 하늘 이미지는 하늘만 담은 장면 렌더다. UI는 모두 편집 가능한 텍스트와 컴포넌트 인스턴스로 만들었다.
