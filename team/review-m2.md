# M2 검수 (아트 디렉터, 2026-10-17 · 리더 커밋 1739394 기준)

## 검수 방법

- **사용자 데이터는 건드리지 않았다.** 헤드리스 크롬을 격리 프로필(작업용 임시 폴더)로 띄워 localhost:5173을 열었다.
  - 사용자 브라우저와 대시보드 탭은 열지 않았다.
  - 샘플 데이터는 그 격리 프로필 안에서만 '샘플로 시작'으로 넣었다.
  - 첫 실행 캡처는 `?onboarding=1`(메모리 모드)이다.
  - ⌘K에서는 Enter를 누르지 않았다.
- 하늘은 소프트웨어 WebGL(SwiftShader)로 그렸다. 덜 그려진 프레임은 없었지만, 별이 GPU 화면보다 굵고 빽빽해 보일 수 있다.
- 모든 실행에서 콘솔 오류·경고는 0이었다.
- 캡처: `team/figma-assets/m2-app/`(새 17장 + 한눈 시트 `sheet-m2-landscape.jpg`). 리더의 map-notes-* 파일은 그대로 두었다.

## 통과

| 항목 | 결과 |
|---|---|
| 1초 메모 | `n` → 입력창 포커스(textarea "생각 하나"). 데스크톱 칸은 가운데 아래 ≈540px. 과목 칩을 자동 추정한다("열역학 …" → 물리 → 저장 뒤 일반물리). Enter 저장 뒤 '별가루 3 → 4', 토스트 없음. 폰은 아래 시트 113px · 카메라 · 금빛 ↑ |
| 별가루함 | 오늘 줄 `별가루 n ›`. 가로 화면에서 글 구역을 그 자리에서 바꾼다(은하는 오른쪽에 보임). 줄 = 글 + 과목 · 시각. 노트로 · 할 일로 · 보관, 보관함 › |
| 편집기 | 본문 Noto Sans KR 17px / 줄 간격 29.75px(1.75), 글 폭 580px. 폰 16px. 종이는 평평한 단색(리더 결정). 수업 노트 틀 = 핵심(목록) · 질문(체크) · 구분선 · 한 줄 요약(인용) + 메타(과목 · 날짜 · 강의실). 저장 점(`np-save is-saved`) |
| `/` 메뉴 | 빈 줄에서만 열린다. 낱말 앞 '/'에서는 열리지 않는 것을 확인했다. 8종 + 단축 표기 |
| `[[` 제안 · 링크 | 제목 + "링크 2" + "＋ 새 노트 ‘엔’". 고르면 링크 글자 + 과목색 밑줄. links 표에 바로 들어간다 |
| 백링크(문서 노트) | "이 노트를 가리키는 노트 3", 줄마다 제목 + 링크가 든 문장 |
| 노트 화면 검색 칸 | "평형" → 4개로 그 자리에서 거른다 |
| ⌘K | 노트 3 → 메모 1 → 마지막 "메모로 저장 · ‘엔트로피’". 일치 글자 강조, 본문 일치는 발췌 줄 |
| 시간표 격자 | 글 구역 안(띠 위), 수업 칸 = 과목색 막대 + 면, 지금 선 금. 끌어 그리기는 시험하지 않았다(보기만) |
| 보관 카드 | "내 은하 보관 / 아직 없음 / [내보내기] [가져오기]". 데스크톱에서는 아이폰 줄이 없다(맞음) |
| 첫 실행 | 시작 → 과목(칩 · ×) → 시간표(캘린더 파일 · 직접 그리기 · 다 됐어요 · 나중에) → 내 은하. 은하 보이기 중간 프레임에서 회전 없이 물러남을 확인했다 |

**확인하지 못한 것:** 지도 렌즈 · 검색 별 반짝(D8) · 별가루 흐름(D3), 시간표 끌어 그리기, 가져오기 합치기·바꾸기(파일 왕복), 세로·폰 별가루함 시트, 실기기 한글 IME.
