### 0-2. 사건 층 규칙 (모든 행에 적용)

1. **그리는 곳:** 사건은 은하를 다 그린 뒤 **동적 사건 층 1장**에 가산 합성한다. 위치는 월드 좌표를 투영하고, **크기는 화면 px로 고정**한다(가까워져도 커지지 않는다).
2. **가림:** 사건 자리가 카메라에서 볼 때 원반 평면 반대편에 있으면 밝기 ×0.5. **예외: R(아래에서)에서는 가림 계산을 끈다.** 데이터 별은 원반 위(y +0.1–0.3u)라 아래에서 보면 늘 반대편이지만, 복습 별은 R의 주인공이므로 줄이지 않는다.
3. **안 보이면:** 자리가 화면 밖이거나 가장자리 24px 안, 또는 투영 크기가 별 1개보다 작아 구별이 안 되면 **애니메이션 없이 최종 상태로만 바꾼다(그리기 0, 깨우기 0).** 다음에 그 장소에 가면 최종 상태가 보인다.
4. **동시성 · 대기열:** design-v3-motion 1장 그대로. 큰 사건(V1·V2·V13) 1개, 작은 사건(V1s·V3·V4·V11) 3개. 150ms 간격, 대기 2초 넘으면 최종 상태로 건너뜀.
5. **밝기 상한(공통):** 사건이 더하는 빛은 어느 픽셀에서도 **코어 최고 휘도의 0.9배 이하.** 사건 면적 합 ≤ 화면 2%. 화면 전체 밝기 변화 ≤ 초당 10%. 글자 안전 마스크(2-2) 안에서는 사건 층 ×0.3.
6. **멀미:** 사건은 **카메라를 움직이지 않는다.** 위치가 움직이는 것은 V2 빛 머리뿐이다(≤ 400px/s). 화면 전체를 움직이는 효과·롤·흔들림 0. 자동 시야 각속도 합 ≤ 1.5°/s는 사건과 무관하게 지킨다.
7. **배터리:** 사건이 시작되면 전력 상태는 '활동'(60fps)으로 오르고, **사건이 끝나고 2초 뒤 '평소'(30fps)로 돌아간다.** 사건 중 별의 생애·성운 흐름은 그대로 두고 새로 늘리지 않는다. 쉼·숨김 상태에서 사건이 오면 최종 상태만 기록하고 깨우지 않는다(돌아올 때 600ms 램프 위에 보임).
8. **절제 · 정지:** design-v3-motion 1장 '모드별 대체 규칙' 그대로. 정지·OS 동작 줄이기 = 최종 상태 즉시, 정지 장면 1회 다시 그림.
9. **밝기 단위:** 별 밝기 %는 '세트 별'(별빛 금 `#F3D29A` 2.4px) = 100% 기준. 할로·스파이크는 불투명도 상한.

### 2-2. 안전 마스크 (렌더러 상수)

- **모양:** 장소 × 레이아웃(가로·세로·폰)마다 사각형 1–2개 = 위 표의 '글 구역'. 가장자리 페더 120px(폰 64px).

## 3. 낮(밝은) 테마의 3D 방향: '3D 건판'

v3의 낮 = 천체 사진 유리 건판(음화)을 3D로 잇는다. **장면은 밤과 똑같이 HDR로 그리고, 마지막 합성 한 단계에서만 음화로 바꾼다.** 그래서 별 생성·비행·사건 코드는 테마를 몰라도 된다.

### 3-1. 합성 셰이더 (`uPlate` 0 = 밤, 1 = 낮)

```glsl
vec3  hdr  = sceneLinear * uExpo;                    // 밤과 같은 장면·노출
float L    = dot(hdr, vec3(.2126, .7152, .0722));
float Lb   = dot(bloomLow, vec3(.2126, .7152, .0722)); // 이미 있는 블룸 저해상도 = 저역
float pt   = clamp((L - Lb) * 6.0, 0., 1.);           // 점(별) 마스크 / 나머지는 안개(원반·성운)
float D    = pow(1.0 - exp(-1.35 * L), 0.85);         // 필름 농도 (H–D 곡선)
float warm = clamp((hdr.r - hdr.b) / (hdr.r + hdr.b + 1e-4) * 1.5 + .5, 0., 1.);
vec3  inkB = mix(vec3(.549,.592,.678) /*#8C97AD*/, vec3(.431,.384,.325) /*#6E6253*/, warm);
vec3  inkS = vec3(.102,.125,.188);                    // #1A2030 별 점
float Dmax = mix(.30, .85, pt);                       // 안개 30% · 별 85%
vec3  ink  = mix(inkB, inkS, pt);
vec3  paper = mix(vec3(.953,.945,.925) /*#F3F1EC*/, vec3(.918,.906,.878) /*#EAE7E0*/, smoothstep(.80, 1., uv.y)); // 아래 20% 바램
paper *= 1.0 - .03 * smoothstep(.55, .95, length(uv - .5) * 1.4);                 // 유리판 모서리 3%
float d  = min(Dmax * D, uSafeD);                    // 안전 마스크 안: uSafeD = .09 (→ #DEDAD1 이상)
vec3 day = paper * (1.0 - d * (1.0 - ink));          // 곱하기 합성 = 종이 위 먹
out = mix(nightTonemapped, day, uPlate);             // 전환 600ms 동안만 둘 다 계산
```

- **암흑대(먼지)**는 L이 낮으므로 저절로 종이색 틈이 된다(v3 '암흑대는 밝은 틈').
- **코어**는 검은 구멍이 되면 안 된다. 안개 농도 상한 30%라 코어는 옅은 세피아 얼룩 `#6E6253` 30%에서 멈춘다.
- **푸른 팔**은 회청 `#8C97AD`, 금빛 팽대부는 세피아 `#6E6253`. 색은 그 둘 사이에서만 고른다(채도 낮게).
- 배경 별 하늘 구: L이 1.2px 별 문턱 아래인 점은 버린다(종이에 먼지처럼 보임). 남는 점만 먹색 점.

1. **(모션) 사건은 월드 자리에 붙고, 카메라를 움직이지 않으며, 짧게 끝난다.** 사건 층 1장에 화면 px 크기로 가산. 안 보이는 장소에서는 애니메이션 없이 최종 상태만(그리기 0). 사건 끝 2초 뒤 '평소' 30fps로 복귀. 유성(V5)·별가루 모임(V7)·레일 아이콘 반짝은 없다.
