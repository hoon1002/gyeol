# 디자인 M2: 입구

작성: 아트 디렉터 · 2026-10-17 · 바탕: `team/m2-brief.md`, `plan-v4-final.md` 3-2·4-1·4-2·4-3, `design-m1.md`, M1 실제 앱 캡처(`figma-assets/m1-app/`), `src/galaxy3d/zones.ts`(SKY_ZONES)

> **한 줄:** 적는 데 1초, 하늘은 그것을 별가루로 받는다. 정리하면 별가루가 과목 성운으로 흘러가 노트 별이 되고, 링크는 은하를 가로지르는 빛줄기가 된다.

**누가 무엇을:** 앱 A(글) → 3·4·5·7장. 앱 B(입구) → 0·1·2·6·8·9장. 모션 → 10장. **셋 다 0장과 11장을 읽는다.**

## 0. 공통 · 이번에 정한 것

- **글은 3줄:** 명사구 1 + 메타 1 + 동작 1. 버튼 아래 설명문, 안내 문단, 감탄 문구는 쓰지 않는다.
- **숫자는 중립:** 별가루 n, 노트 n은 늘 `--text-3` 모노로 쓴다. 0이면 그 줄을 숨긴다. 빨간색, '밀림', '아직 n개', 느낌표는 쓰지 않는다.
- **피드백은 하늘이 한다:** 저장·옮기기·보관에는 토스트를 띄우지 않는다. 오류만 평서문 한 문장으로 쓰고 `--danger` 글자를 쓴다(M4).
- **글 구역:** 모든 새 화면은 `SKY_ZONES`(M1) 안에 들어간다. 메모 칸·⌘K·시트처럼 떠 있는 층은 예외이고, 유리(`blur 20`)로 덮는다.
- **오늘의 '최근' 장은 뺀다**(앱 개발자 질문에 대한 결정).
  - 한 화면 한 초점이므로 오늘은 3줄 + 조용한 줄 1개(별가루 · 계획)로 끝낸다.
  - 최근 노트는 ⌘K 빈 상태 '최근 5'와 노트 목록 맨 위(최근 수정 순)가 맡는다.
- **크롬:** 레일 맨 아래와 폰 독 가운데의 ＋가 이번에 살아난다(1장).

| 오늘 화면 (M2) | 가로 | 세로 · 폰 |
|---|---|---|
| 3줄 | 그대로 (명사구 / 메타 / 동작) | 그대로 |
| 조용한 줄 | 동작 아래 16px: `별가루 3 ›` (모노 13px `--text-3`, 0이면 숨김) | 폰 맨 아래 줄 하나에 왼쪽 `별가루 3`, 오른쪽 `계획 ›` |

## 2. 별가루함 (앱 B)

### 2-1. 여는 곳 · 모양

- **여는 곳:** 오늘의 조용한 줄 `별가루 3 ›`, ⌘K '별가루'.
- **모양:**
  - 가로: 오늘 글 구역 `(0.08, 0.30)–(0.40, 0.80)`을 **그 자리에서 바꾼다**. 오늘 3줄은 180ms에 나가고 별가루함이 들어온다. 은하는 오른쪽에 그대로 보인다. 정리할 때 별가루가 성운으로 흘러가는 모습이 보이게 하려는 것이다.
  - 세로·폰: 아래 시트, 높이 세로 56% · 폰 60%, 위 모서리 20px. 은하 위쪽은 보인다.
- **하늘:** 어둡게 하지 않는다. 열려 있는 동안 공전 ×0.3(useFieldPause).
- **머리:**
  - 명사구 "별가루"(Hahmlet 600 22px), 메타 "3"(모노 `--text-3`).
  - 닫기: 가로는 '‹ 오늘', 세로·폰은 손잡이와 Esc.
  - 맨 아래 조용한 줄 "보관함 ›"(보관한 것 다시 보기). 되돌리기는 이 줄이 맡는다.
- **비었을 때:** 메타만 "비었어요", 목록 없음.

### 2-2. 메모 한 줄

| 부분 | 모양 |
|---|---|
| 글 | 15px `--text-1`, 2줄까지 보이고 나머지는 말줄임 |
| 메타 | 과목 점 6px + 과목 이름 · 시각 "14:20" (모노 11px `--text-3`) |
| 사진 | 오른쪽 40px 정사각 썸네일, 모서리 6px |
| 동작 | 조용한 버튼 셋 **노트로 · 할 일로 · 보관**. 데스크톱은 줄 hover·focus 때 보이고, 폰은 줄을 누르면 펼쳐진다 |
| 키 (줄에 포커스) | ↑↓ 이동, `Enter` 노트로, `T` 할 일로, `E` 보관, `S` 과목 바꾸기 |

- **노트로:**
  - 오늘 그 과목의 수업 노트(classKey)가 있으면 그 노트 끝에 문단으로 붙인다.
  - 없으면 새 노트를 만든다. 제목은 첫 줄의 앞 40자이고, 나머지 글과 사진은 본문이 된다. A의 `openOrCreateNote`를 쓴다.

- **보관:** state를 `archived`로 바꾼다. 지우지 않는다.
- 줄이 사라질 때는 높이 접힘 + opacity 200ms. 하늘 반응은 10장 D3–D5에 있다.

### 3-4. 자동 저장 표시

- 메타 줄 끝에 4px 점 하나를 둔다. 바뀌면 빈 원(`--text-3` 테두리)이 되고, 저장되면(0.6초 디바운스) 채운 점이 된다(200ms). 글자 '저장됨'은 쓰지 않는다.

- 하늘은 자동 저장에 반응하지 않는다(M1 #49).

## 4. 링크 (앱 A · 모션)

### 4-1. `[[` 제안 상자

- **자리:** 커서 아래 6px, 너비 320px. 폰은 종이 폭 − 16px이고 키보드 바로 위에 붙는다.
- **면:** `--surface-2` 94% + `blur 20`, 모서리 12px, `--shadow-2`.
- **목록:** 최대 6줄, 줄 높이 40px. 줄 = 과목 점 6px + 제목 15px(일치 글자 굵게) + 오른쪽 모노 11px "링크 3".
- **마지막 줄:** 제목이 정확히 같은 노트가 없으면 늘 "＋ 새 노트 ‘입력어’"를 둔다.
- **키:** ↑↓ · Enter/Tab 고르기 · Esc 닫기(쓴 `[[` 글자는 남김). 목록은 조합이 끝날 때만 다시 거른다.

### 4-2. 링크 글자

| 상태 | 모양 |
|---|---|
| 있는 노트 | 대괄호 없이 낱말만, `--text-1`. 밑줄 1px, 아래로 3px, 색 = 그 노트 과목색 60%(과목 없으면 금 55%). hover·focus 때 밑줄 100% |
| 없는 노트 | `--text-2`, 밑줄 1px **점선** `--text-3`. 누르면 그 제목으로 새 노트(빈 노트, 과목은 지금 노트와 같게) |
| 막 생긴 링크 | 밑줄이 0 → 60%로 200ms. 하늘은 10장 D7 |

### 4-3. 지도의 노트 별 · 빛줄기 (1,000노트 · 2,000링크 기준 상한)

| 항목 | 값 |
|---|---|
| 노트 별 자리 | 지도 성운 `LANDMARKS.graph`의 과목 가지 중심(반지름 1.5u, 6방향)에서 id 해시로 정한 가우시안 σ 0.5u, y ±0.1u. 한 과목이 150개를 넘으면 σ × √(n/150) |
| 노트 별 크기 · 밝기 | 링크 수 0 → 8 이상을 로그로 이어 **1.2 → 2.6px, 35 → 80%**. 색은 흰빛 `#DCE4FF`에 과목색 20%를 섞는다. 할로는 링크 많은 상위 12개만(4px, 20%) |
| 빛줄기 | **0.75px**(화면 고정). 색은 두 끝 과목색을 각각 흰빛과 30%씩 섞은 그라데이션. 같은 과목이면 직선, 다른 과목이면 원반 위로 휜 호(가운데 y + 0.15 × 길이, 최대 0.6u, 8토막) |
| 빛줄기 밝기 | 줄마다 `min(14%, 2.2 / √링크 수)` → 100줄이면 14%, 2,000줄이면 4.9%. 화면 길이가 짧은 변의 40%를 넘으면 ×0.5. 가산 합성 결과는 한 픽셀에서 35%를 넘지 않게 자른다 |
| 고른 별 | 금 3.2px. 그 별의 선 60%, 나머지 선 16%, 나머지 별 50%(M1 #31) |
| 라벨 | 없다. 누를 때만 별 정보 칸(M1 지도 오른쪽 아래 구역)에 "제목 / 과목 · 링크 n / 열기"를 쓴다 |
| 보이는 장소 | M은 전부. N은 별만(책등 위 점), 빛줄기는 0. T·P·R·F는 노트 층 0 |

1. **(앱 B) 메모는 같은 틱에 연다.** 미리 마운트한 칸의 `inert`를 키 핸들러 안에서 풀고 `focus()`를 부른다. Enter는 조합 중 무시한다. 저장하면 칸이 닫히고 80ms 뒤 `dust()`가 불린다. 토스트는 없다.
2. **(앱 A) 편집기는 평평한 종이, 17px/1.75, 글 600px.** 노트 SKY_ZONES 안에 들어간다. 툴바 없이 마크다운 단축과 빈 줄의 `/`로 쓴다. 조합 중에는 제안·저장·단축을 멈춘다. 링크 밑줄은 과목색 60%, 없는 노트는 점선이다.
3. **(모션) 순간 ①의 은하 보이기는 회전 0이다.** 첫 실행 자세의 방향이 오늘 자세와 같으므로 물러나기만 한다(2.6초). 빛줄기 밝기는 줄마다 `min(14%, 2.2/√링크 수)`로 정하고, 픽셀 합은 35%에서 자른다. 별가루는 24점이 상한이다.

**리더 결정이 필요한 것**
1. **첫 실행 순서:** 브리프는 '여섯 번째 과목 → 은하 보이기'이다. 이 문서는 **과목 → 시간표 → 은하 보이기**로 바꿨다. 은하 전체가 처음 보이는 순간을 마지막 보상으로 두기 위해서다. 여섯 번째 과목에서는 시간표 단계로 자동으로 넘어간다. 브리프 순서를 지키려면 2·3단계만 바꾸면 된다.
2. **샘플 데이터 표시:** '샘플 지우기'에는 샘플 행을 알아볼 표시(예: `seed: true` 또는 id 접두어)가 필요하다. 스키마를 바꾸면 version 3이다.
3. **하늘 계약 이름:** 브리프 안 그대로 쓰고 하나만 더했다. `fileDust(id, subjectId | null, to?: 'note' | 'task' | 'archive')`의 세 번째 인자(기본 'note')다.
4. **⌘K 결과 수:** 8줄 고정으로 정했다. 노트가 많아도 더 보기는 노트 화면 검색 칸이 맡는다.
