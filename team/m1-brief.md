# M1 브리프 — 3D 은하를 앱에 옮기기 (리더 작성, 2026-10-17)

## 사용자 원문
> 좋아, 이 방향으로 M1(3D 은하를 앱에 옮기기) 시작해줘

(그 전에 확정된 것: 구형 360° 트랙볼, 앞을 지나가는 별, 장소마다 다른 시점(design-v4 8장), 집중 = 정면 시계판, 배터리·발열 최우선.)

## M1 범위 (plan-v4-final 3-4, 5장)
1. **앱 하늘을 3D 은하로 교체:**
   - 캔버스 1개와 rAF 1개, 레이어 규칙(fx/index.ts 머리말)은 그대로 둔다.
   - 2.5D 하늘은 WebGL2 실패나 C 등급일 때만 쓰는 대체로 남기고, 지연 로드한다.
2. **장소 6 + 설정 시트:**
   - 장소는 오늘 · 노트 · 지도(← 그래프) · 복습 · 계획(← 플래너) · 집중이다.
   - 설정은 장소가 아니라 시트다. 은하는 비행하지 않고 어둡고 느리게만 바뀐다.
   - 옛 주소 /graph·/planner·/settings는 새 주소나 시트로 이어 준다.
3. **장소마다 3D 시점** (design-v4 8장 그대로)과 장소 사이 비행. 비행 박자는 노출 → 커밋 → 비행이다.
4. **'은하 회전: 켬 · 느리게 · 끔' 설정**과 사용자 드래그 트랙볼:
   - 드래그는 빈 하늘에서만 받는다. 글이나 버튼 위 드래그는 앱 것이다.
   - 끔이거나 OS 동작 줄이기면 자동 회전은 0이고, 장소 이동은 0.5초 어둡게 바꾸기로 한다.
5. **기존 하늘 사건 51개를 3D 자리로 옮긴다.** 유지·합침·삭제는 아트 디렉터 표를 따른다.
6. **UI를 실루엣에 맞춘다.** 글이 놓이는 자리는 어두운 하늘이어야 한다(아트 디렉터 배치표). 집중 타이머 링은 은하 원반 둘레의 베젤이다.
7. **전력:** src/perf/scheduler.ts의 규칙은 그대로다(집중 20초 → 쉼, 노트·복습·설정 30초 → 깊은 대기, 숨김 0). 3D 전력 상태와 해상도 배율도 시제품 값을 따른다.
8. **M1에서 하지 않는 것:** ＋메모·별가루함·노트 편집기(M2), FSRS(M3), 의식(M4), 펜(M5).

## 완료 기준
- 장소 이동 30번에서 가장 긴 프레임이 20ms 이하이고, 활동 GPU(상한을 푼 작업량)가 5ms 이하다.
- 동작 줄이기에서 자동 회전과 비행 회전이 0이다.
- 기존 기능 깨짐 0(장소 화면, ⌘K, 별 누르기, 집중 타이머, 테마 밤·낮), 콘솔 오류 0, typecheck·build 통과.
- 장소 6곳과 설정 시트를 실제 앱으로 찍은 1440×900 화면 + 세로 820×1180 화면.

## 계약 (리더 확정 — 바꾸려면 리더에게)
`@/fx` 공개 API의 이름과 시그니처는 유지하고, 추가만 한다. 앱 코드는 `@/fx`에서 내보내는 것만 쓴다.

- `MoodName`에 `'map'`, `'plan'`을 더한다. `'graph'`, `'planner'`는 그대로 받아서 같은 장소로 보낸다.
- `FieldProvider`에 `rotation?: 'on' | 'slow' | 'off'`를 더한다.
- `useSkySheet(open: boolean)`: 설정 시트가 열려 있는 동안 은하를 어둡게(노출 ×0.65) 하고 느리게 한다. 비행은 없다.
- `useSkyAnchor(name, cb)`: 은하의 화면 위치를 CSS px로 알린다. 형식은 `{ x, y, r, visible }`.
  - 이름은 `'focus-disk'`(집중 원반 중심·반지름)와 `'core'`(은하 중심)다.
  - 비행이 끝날 때, 크기가 바뀔 때, 집중 시계로 움직일 때만 부른다. React를 다시 그리지 않도록 콜백으로 준다.
- `useSkyDrag(enabled)`: 빈 하늘 드래그 트랙볼을 켜고 끈다. 오늘·지도·집중은 켜고, 노트·복습·계획은 끈다(글 쓰기·카드 조작 우선).
- 기존 사건 API(birthStar·relight·drawLink·…)와 `useSkyPick()`의 이름은 그대로 두고, 결과에 `world: [x, y, z]`를 더한다.
