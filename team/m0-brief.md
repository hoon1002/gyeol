## M0 목표

"앱을 열면 이미 압도적이다"를 증명하는 기반. 기능은 아직 비어 있어도, 셸·내비게이션·결 모션·오늘 화면·빈 상태가 완성품 수준으로 보이고 움직여야 한다.

- 화면 구성 v2: **한 화면에 하나의 초점**. 정보 밀도를 낮추고 점진적으로 드러낸다 (`team/design-v2.md`, 디자이너).
- 결 모션 v2: 히어로에만 있던 등고선·물결을 앱 전체의 언어로. GPU(WebGL2) 기반, 풍부하지만 필기·타이핑 중에는 조용히.
- 기술 기반: Vite 8 + React 19 + TS 7(이미 설치됨), TanStack Router, Zustand, Dexie 4, motion, cmdk, vite-plugin-pwa.

## M0 완료 기준 (리더 검증용)

1. `npm run build` 성공(타입 오류 0), `npm run dev`로 실행 시 콘솔 에러 0.
2. 6개 공간(오늘·노트·그래프·복습·플래너·집중)으로 이동 가능, URL 라우팅, 새로고침해도 같은 화면.
3. 폰(390) · iPad 세로(820) · iPad 가로(1180) · 데스크톱(1440)에서 design-v2의 셸로 바뀌고 가로 스크롤 0.
4. 결 필드가 화면마다 다른 분위기로 살아 움직이고, 누르면 물결이 번진다. 화면 전환에 결 연출이 있다.
5. 오늘 화면이 design-v2대로 "한 초점" 구성이며 샘플 데이터(시드)로 채워져 있다.
6. ⌘K(Ctrl+K) 팔레트가 어디서나 열리고 공간 이동·테마 전환이 된다.
7. 테마 다크/라이트/시스템, 모션 풍부/줄이기 설정이 동작하고 저장된다. OS '동작 줄이기'면 연출이 즉시 전환.
8. Dexie 스키마(과목·노트·카드·세션 등 M0에 필요한 최소)와 시드, 새로고침 후 데이터 유지.
9. PWA 매니페스트·서비스워커로 설치 가능, 오프라인 새로고침 시 셸이 뜬다(빌드/프리뷰 기준).
10. 숨긴 탭·화면 밖에서는 렌더 루프가 멈춘다(배터리). iPad 120Hz에서 결 필드 프레임 예산 4ms 이하 목표.
