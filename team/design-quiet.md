# 디자인 M3: 조용한 화면 (글 줄이기 감사)

작성: 아트 디렉터 · 2026-10-17 · 바탕: `team/m3-brief.md`, 소스 전수 추출(JSX 글·문자열, aria-label 제외), M2 캡처(`figma-assets/m2-app/`)
손글씨 도구 칸·둥근 메뉴·제스처는 `design-ink.md`(손글씨 설계자)가 정한다. 이 문서는 **지금 있는 화면의 글**만 다룬다.

> **한 줄:** 늘 보이는 앱의 말은 화면마다 0–1줄이다. 나머지는 아이콘·숫자·하늘이 말하고, 이름은 손을 대면(hover 600ms · 길게 500ms) 나온다.

---

## 0. 원칙

**글의 세 종류**

| 종류 | 예 | 규칙 |
|---|---|---|
| ① 내 글(데이터) | 노트 제목, 메모, 카드 앞면, 과목 이름(격자 칸 안), 템플릿 제목(핵심·질문 등) | **남긴다.** 사용자가 쓴 것이다 |
| ② 숫자 | 시각 `15:00`, `25:00`, `D-6`, 개수 | **남긴다.** 늘 아이콘이나 색 점과 짝을 짓고, 모노 `--text-3`, 빨강은 쓰지 않는다 |
| ③ 앱의 말 | 화면 제목, 메타 줄, 버튼 글자, 안내, 토스트 | **감사 대상.** 늘 보이는 것은 화면당 0–1줄 |

- **부르면 나오는 말**(메뉴·툴팁·되돌릴 수 없는 확인·오류)은 1–2낱말까지 허용한다. 오류와 지우기 확인만 문장을 쓴다(M4 규칙).
- **결정 기호:**

| 기호 | 뜻 |
|---|---|
| 남김 | 그대로 둔다 |
| 뺌 | 화면에서 없앤다. 스크린리더용 이름은 남긴다(5장) |
| 아이콘 | 아이콘으로 바꾼다. 이름은 툴팁으로 |
| 숫자 | 숫자와 아이콘만 남긴다 |
| 길게 | 평소엔 숨기고 hover 600ms · 길게 500ms로 보인다 |
| 첫 회 | 기능마다 처음 한 번만 그림 위주로 보인다(4-2) |

- **토스트는 모두 뺀다.** 바뀐 컨트롤의 상태와 하늘이 응답한다. 스크린리더에는 `aria-live`로 같은 말을 준다.
- 개발 모드 전용 '개발용' 단원(Settings.tsx:221–257)은 감사에서 뺀다. 출시 화면에 나오지 않는다.

## 5. 접근성 (글을 지워도 이름은 남는다)

- **모든 아이콘 전용 컨트롤에 `aria-label`**(툴팁과 같은 말: "새 노트", "노트로 옮기기", "보관", "알았음"). 장식 아이콘은 `aria-hidden`.
- **세그먼트**는 `role="radiogroup"` + `aria-label`("테마")이고, 칸은 `role="radio"` + `aria-checked`. 토글은 `aria-pressed`.
- **숫자 + 아이콘**에는 sr 문장을 붙인다: `▤ 13` → "카드 13장", `NewLink 3` → "이 노트를 가리키는 노트 3개", `D-6` → "시험까지 6일".
- **화면마다 sr-only `h1`**(장소 이름)을 둔다. 시트는 `h2`.
- **토스트를 뺀 자리는 `aria-live="polite"`** sr-only 문장으로 알린다("저장했어요", "보관했어요", "테마 낮").
- **색만으로 말하지 않는다:** 과목 점에는 이름(aria · 툴팁)이 있고, 고른 점은 고리를 두른다. 평가 ↺ · ✓는 모양이 다르다.
- 길게 누르기로만 닿는 것은 없다. 모두 키보드(`Shift+F10` · 메뉴 키)와 ⌘K로도 닿는다.
- 대비: 아이콘 `--text-2` ≥ 3:1(그래픽 기준), 툴팁 글 ≥ 4.5:1.
