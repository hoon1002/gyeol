- **자전(차등 회전)은 정점 셰이더가 시간으로 계산**: Ω(r) = 1.2°/s × 3 ÷ max(3, r) (코어 1.2°/s, 15u에서 0.24°/s). 막대·팽대부는 코어 속도로 단단히 돈다(막대가 비틀리지 않게). CPU는 매 프레임 카메라 행렬·유니폼만 바꾼다 — **JS 0.1ms/프레임**.
- 피사계 심도: 초점(=바라보는 점) 거리에서 멀수록 점의 표준편차가 커지고 최고 밝기가 같은 비율로 줄어든다(빛의 총량 보존). 먼 은하는 부드럽게, 가까운 별은 또렷하게.
- 시차는 진짜 3D 원근에서 나온다(2.5D 때의 '깊이 층' 꾸밈이 필요 없다).
- 카메라: 바라보는 점 + 방위·고도·거리. **롤 변화 0**, 원반이 화면에서 57° 대각선으로 흐르도록 고정 기울기(−57°) + 렌즈 이동으로 바라보는 점이 화면 (0.66, 0.44)에 온다(FOV 50° 고정). 장소는 은하와 같이 돈다(바라보는 점·방위가 Ω(r)·t만큼) → 머무는 동안 가까운 별은 그대로, 먼 팔과 코어는 차등 회전으로 흐른다.
- 비행: 시작 상태 → 목적 장소를 매 프레임 다시 계산(장소가 돌고 있으므로), ease-in-out, 1.2–1.8초, 방위 변화 ≤ 30°, 호(거리 +≤12%, 고도 +≤3°), 비행 중 재입력은 지금 위치·속도에서 이어 받기(Hermite).
- 카메라 호흡: 방위 ±3°(40초) · 고도 ±1.5°(31초) · 거리 ±2%(24초). 첫 진입 내려앉기 0.84 → 1.0(1.3초). 드래그: 방위 ±35° · 고도 ±12°, 최대 90°/s, 손을 떼면 관성 ≤ 0.6초 후 멈춤. 휠: 거리 ×0.35–2.6.
- 회전 설정: 켬(코어 1.2°/s) · 느리게(0.4°/s) · 끔(0). **OS 동작 줄이기면 끔 + 호흡·관성 0 + 비행은 즉시 전환.**

## 4. 리스크

1. **멀미:** 회전·궤도는 v3의 '화면 전체 회전 금지'를 바꾼다. 자전은 매우 느리고(코어 1.2°/s), 카메라 롤 0, 비행 중 시야 각속도 ≤ 30°/s로 묶었다. 사용자 테스트 필요. 설정에서 끔·느리게, OS 동작 줄이기 존중.
2. **글 가독성:** 3D 은하는 2D 하늘보다 밝은 부분이 많다. 글자 구역 안전 마스크(v3의 #161C2C 상한)를 합성 단계에 그대로 옮겨야 한다.
3. **iPad 채우기 비용:** 원반 가까이 큰 스프라이트·구름. 동적 해상도·점 크기 상한 없이는 비행 중 프레임 저하.
4. **차등 회전의 팔 감김:** 오래 켜 두면(수십 분) 팔이 감긴다. 밀도파 방식(팔 무늬는 단단히 돌고 별이 팔을 지나간다)으로 바꾸거나, 세션 시계를 30분 주기로 되감는다(보이지 않을 때).
5. **배터리:** 정지 화면에서도 자전 때문에 계속 그린다. 글이 많은 화면은 자전 ×0.3, 30fps 상한(design-v4 §6), 탭이 숨으면 정지.

## 6. 2차 품질 패스 (2026-10-17, 리더 아트 디렉션 반영)
- **고리 → 나선:** 팔마다 길이 방향 밝기(코어 쪽 밝음 → 바깥 흩어짐, 지수 5.5u), 끊김(두 주파수 사인 곱으로 매듭·틈), 큰 팔은 13u 넘어 사라지고 작은 팔은 6–11u에만. 큰 팔은 8.5u 바깥에서 35%가 갈라진 가지로, 별 10%는 팔에서 비스듬히 뻗는 깃털(스퍼). 피치는 design-v4의 13° 대신 **15°**(13°는 화면에서 동심원으로 읽혀서 — 아트 디렉터 확인 필요).
- **별 덩어리:** 젊은 별 65%를 팔 바깥 가장자리 900개 덩어리(σ 0.05–0.37u)에, 오래된 별은 2스케일 얼룩으로 밀도 변조. HII는 2,600개의 작은 분홍 매듭(0.03–0.15u)으로 덩어리 곁에.
- **먼지:** 16,000개의 가늘고 긴(3.6:1) 조각을 팔 안쪽 가장자리에, 사인 틈으로 끊고 15%는 갈라진 가지로. 매끈한 호 대신 끊긴 실.
- **막대·팽대부:** 막대 별 60%, 막대 빛 160조각으로 막대 모양, 팽대부 밝기 ×0.65로 하얗게 날지 않게. 먼 은하 9개(하늘 구 위 타원 얼룩).
- **성능:** 점 크기 상한 40px. 1440×900 · DPR 2(2880×1800, 5.2MP) 정지 119fps · p95 9.0ms, **비행 8회 최장 9.4–17.6ms(목표 ≤ 20ms 충족)**, p95 8.5–9.4ms. 구름 21k. 입자 생성 360ms(메인 스레드 — Worker는 남은 일).
- 렌더(`renders-3d/`, 이전 것은 `v1/`): R4-01 today · R4-02 focus(원반 안) · R4-03 graph(HII 복합체). 미리보기 창이 세로 800×1194라 1440×900 · 1180×820 가로 렌더는 이 환경에서 원본 크기로 뽑지 못했다 → 앱 통합 때 v3의 가상 화면 타일 방식으로 뽑는다.

## 7. M0 3차 패스 — 360° 확인 · 밀도파 팔 · 전경 별 상한 · 전력 상태 (모션 개발자 인수, 2026-10-17)

### 7-1. 바뀐 구조
- **밀도파(Q2):** 팔 무늬·먼지·HII·젊은 별(새 kind 4)·막대는 패턴 각속도 **Ωp = Ω(9u) = 0.4°/s**로 단단히 돈다. 늙은 원반 별(kind 0)은 방위가 고른 분포로 Ω(r) 차등 회전하고, 정점 셰이더가 지금 패턴 좌표 φ = θ0 + (Ω(r) − Ωp)t에서 팔 밝기(`oldArm`, 4팔 · 폭 σ≈0.7u)와 패턴에 붙은 얼룩으로 밝힌다(`uArm` 바탕 1.0 · 팔 1.4). 그래서 별은 팔을 지나가고 팔 모양은 시간이 지나도 같다(감김 0 — 식으로 보장, 30분 실측은 안 함). 헤일로는 멈춤(2층), 먼 하늘은 카메라 중심(1층).
- **팔:** 끌리는(trailing) 방향으로 바로잡음, 피치 18°(15°는 3/4 뷰에서 고리로 읽힘), 막대 끝 바로가 아니라 6–9u에서 가장 밝게. 먼지 → HII → 젊은 별 순 오프셋(−0.32 · −0.1 · +0.22u). 먼지 투과율 하한 (0.40, 0.30, 0.24) — 먼지띠가 검은 구멍이 아니라 짙은 갈색.
- **Worker 생성(Q7):** `gen.worker.ts`가 입자를 만들고 버퍼를 transfer. 메인 스레드는 올리기 2–3ms만(이전 메인 스레드 생성 311–360ms 멈춤 → 0). 생성 155–162ms(Worker).
- **동적 해상도:** 렌더 타깃은 전체 크기로 한 번 만들고 상태별로 그 안의 일부만 쓴다(재할당 0, `uSrc`로 uv 스케일·클램프). 활동 ×1.0 · 평소 ×0.75 · 깊은 대기 ×0.6 · 비행 중 ×0.8 · 총 픽셀 상한 4.0MP(1440×900 DPR 2 = 5.2MP → ×0.88).
- **그리기 고리:** 활동 = rAF(60 상한), 평소·깊은 대기 = 타이머가 깨운 자리에서 바로 그림(깨우기 = 그린 프레임) + 1초 rAF 맥박(창이 가려지면 1.5초 안에 멈춤), 쉼 = 2초 크로스페이드(속도 → 0, 희미한 별 +20%, 대비 +6%, 밝기 그대로) 뒤 **고리 정지**, 숨김 = `visibilitychange`에서 타이머·rAF 취소. 입력이 오면 600ms 동안 속도가 0에서 차오름. 저전력(배터리 ≤ 20% 비충전 · saveData · `?lowpower=1`)이면 활동도 평소로, 입력 없으면 쉼. 발열 추정(활동 p95 > 25ms 10초) → 2분간 저전력과 같게. 회전 끔·동작 줄이기면 입력 2초 뒤 쉼.

### 7-2. 전력 상태별 측정 (Apple M 계열 · Chrome · 1440×900 CSS · DPR 2 · 120Hz · 등급 A · 오늘 장소, `await __g3d.measure(4, 상태)`)

## 8. 구형 360° 회전 — 쿼터니언 아크볼 (사용자 정정 반영, 2026-10-17)
사용자 정정: "은하 중심을 기준으로 360도 구 형태로 회전". 방위만 360°·고도 8–55°였던 오빗을 바꿨다.
- **자세 = 쿼터니언** `orient`(장소 프레임 안 카메라 회전, 구조물 장소는 패턴 Ωp와 함께 돈다). 눈 = 바라보는 점 + orient·(0, 0, 거리). 오일러각이 없어 **고도 제한 없음, 극을 넘어도 짐벌 락·up 뒤집힘 없음.** 장소 기본 자세는 방위·고도 + 화면 기울기 −57°(원반 장축 57° 대각선)로 만든다.
- **드래그(아크볼):** 끈 방향으로 은하가 굴러간다(0.15°/px, 최대 180°/s, 카메라 좌표 축 (dy, dx, 0) 둘레). 관성은 그 축으로 τ 0.5s(느리게 0.25s), 최대 1.2s, 시작 ≤ 90°/s, 멈춘 자세 유지. 동작 줄이기면 관성 0. 휠·핀치 거리 0.6–1.6배 그대로. 롤은 사용자가 굴린 만큼만 생기고 자동으로는 바꾸지 않는다.
- **자동 공전:** 지금 자세에서 이어서 **은하 축(Y) 둘레**로 1.0°/s(느리게 0.4 · 깊은 대기 0.3), 은하 자전과 같은 방향. 3s 뒤 4s 램프, 입력 300ms 안에 0, 회전 끔·동작 줄이기면 0. 호흡은 은하 축 ±3° · 카메라 가로축 ±1.5° · 거리 ±2%.
- **처음 자리로:** 더블클릭(마우스) · 더블탭(터치·펜, 320ms·30px 안) · 버튼 → 장소 기본 3/4 구도로 slerp, 1.2–2.0s(= 1.2 + 회전각/90°×0.8, 위아래 묶음), 사인 inout.
- **장소 비행:** 목적지는 장소 기본 구도를 은하 축 둘레로 5° 간격 72개 돌려 본 것 중 **지금 자세와 가장 가까운 것**(design-v4 §7-1 '지금 방위 + 장소 오프셋'의 구형 버전 → 보통 회전 3–24°). 최단 slerp, 이동·회전 같은 사인 inout. 길이 = max(1.2 + 회전각/90°×0.8 (≤ 2.4s), 최고 각속도 ≤ 60°/s가 되는 길이, 거리 기준 1.2–1.8s). **큰 회전(약 75° 넘게, 예: 뒤집힌 자세에서 출발)은 60°/s를 지키려고 2.4s를 넘긴다**(173° → 4.5s). 롤은 비행 전체에 고르게 나뉘어 끝에서 목적지 up에 맞는다.
- **모든 각도:** 원반면에 눕힌 먼지·원반 빛 사각형은 시선이 원반면에 가까울수록(|시선·법선| 0.42 → 0.08) 가로축을 법선 쪽으로 세워 두께를 남기고(먼지 ×0.32 · 빛 ×0.5), 빛은 겹치는 만큼 ×0.4, 먼지는 ×2.2. 먼지 투과율 하한도 옆에서는 0.40 → 0.16 → 옆에서 보면 얇은 원반을 가르는 갈색 먼지띠 + 부푼 팽대부, 위에서는 나선 전체, 아래에서는 대칭.
- **검증:** `__g3d.drag(dx, dy, 걸음)`으로 극 넘기 — 세로 4800px(720°, 극 4번) · 대각 · 가로: 걸음당 회전 = 입력(1.8–2.25°), up 변화 ≤ 걸음 각(뒤집힘·튐 0), 한 바퀴 뒤 고도 30°로 정확히 복귀. 비행 8회(뒤집힌 자세 포함) 최장 프레임 16.8–17.7ms(≤ 20ms), 장소 비행 최고 각속도 3.8–60°/s, 처음 자리로(169°, 2.0s)는 최고 132°/s — 1.2–2.0s 지시와 60°/s가 부딪혀 지시 길이를 따랐다. 콘솔 에러 0.

  - 상자 반지름 4 → 3u(가까운 보케가 더 자주 지나감), 후보 4,500개, 밝기 분포 0.004 + u^3.5 × 0.12(대부분 어둡고 소수만 밝게).
  - 드래그·비행 상한 72개(폰 36). 별이 바뀌는 동안 사라지는 별까지 세어도 80 이하. 상한의 80% 속도에서 30ms 안에 감춘다.
  - 원반 안 노이즈 대책: 카메라 6u 안의 은하 별은 정점별 고정 난수로 밀도를 최대 85% 줄이고(0.15 + 0.85·smoothstep(0.5, 6, d)), 밝기를 ×0.3–1로 누른다.
- **발열 추정 오탐 수정:** 창이 가려지거나 탭이 느려져 생긴 긴 간격 때문에 '발열'이 켜져 비행이 30fps로 떨어진 것을 발견했다. 이제 초당 20장 넘게 실제로 그리고 GPU 시간 > 16.7ms일 때만 센다.

## 11. 장소마다 다른 자세 (design-v4 §8, 2026-10-17)
- `Place`에 **화면 롤(장축 각도)·화면 자리(가로/세로)·크기 맞춤 규칙·해상도 배율**을 넣었다. 고정 TILT·SEAT는 장소 값으로 바뀌었다.
  - 비행 중에는 화면 자리가 이동·회전과 같은 사인 이징으로 옮겨 가고, 롤은 slerp로 비행 전체에 고르게 나뉜다.
  - 목적지와 '처음 자리로'는 장소 자세를 은하 축 둘레로 돌린 것 가운데 지금 자세와 가장 가까운 것이다(실루엣은 같다).
- 크기 맞춤(`computeFit`): 장소마다 그 자세·자리에서 눈에 보이는 팔 고리(11.5u)의 긴 지름(또는 가로 폭)이 규칙값이 되는 거리를 이분 탐색한다(화면비별).

| 장소 | 방위·고도 | 롤(장축) | 자리 가로 / 세로 | 크기 (가로 / 세로) | 공전 | 해상도 |

| 오늘 | 210° · +30° | −57° | (0.62, 0.46) / (0.54, 0.40) | 긴 축 = 높이 80% / 가로 폭 = 폭 92% | 1°/s | ×1 |

- **집중의 시계:** 25분에 한 바퀴(0.24°/s)를 은하 축 둘레로 돈다. 각도는 진입 시각에서 계산하고, 쉼에서 돌아오면 ≈ 600ms에 걸쳐 맞는 각도로 따라붙는다. 끌면 그 자세에서 시계가 이어지고, 회전 끔·동작 줄이기면 멈춘다.
- **타이머 자리 미리보기:** SVG 덧층에 원반 둘레 12u 가는 링 + 진행 호(금빛)를 둔다. 집중에서만 보이고, `?ring=1` · '타이머 링' 버튼 · `__g3d.ring(bool)`로 켜고 끈다. 렌더는 2D로 겹쳐 그린다(`capture(…, { ring: true, progress })`).
- **멀미 안전:**
  - 회전 100°가 넘는 비행은 가운데에서 노출 85% · 피사계 심도 ×1.6이 된다.
  - 회전 끔·OS 동작 줄이기에서는 0.5초 어둡게 바꾸기로 이동한다(실측 500ms).
  - 비행 길이 줄(min 3000)은 그대로 두었다.
- **GPU를 지키려고 같이 바꾼 것:**
  - 화면에서 커지는 빛 사각형(s/d > 0.2)은 흐려 없애고, 0이면 정점을 화면 밖으로 보낸다(그래프 장소 구름 3.3 → 약 1ms).
  - 별 흐림 상한을 σ 9 → 6px로 낮췄다.
