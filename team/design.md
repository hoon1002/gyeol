## 1. 디자인 콘셉트 — "결"을 시각 언어로

| 결의 뜻 | 시각 모티프 | 앱에서 쓰는 곳 |
|---|---|---|
| 나뭇결의 **옹이** | 한 점을 중심으로 휘감기는 동심 등고선 | 히어로: 커서·손가락이 옹이가 되어 결이 휘어짐. 로고 심볼 |
| 물결 | 누른 자리에서 번지는 고리 | 터치·클릭 피드백(히어로), 집중 모드 배경의 느린 흐름 |
| 등고선(지도) | 4번째 선마다 굵은 "계곡선" | 등고선 필드의 위계(얇은 선 0.9px / 굵은 선 1.3px), 잔디·통계의 "층" 표현 |
| 나이테 | 해마다 한 겹씩 늘어나는 고리 | W2 '나의 결': 주마다 한 겹, 그 주에 가장 많이 공부한 과목 색 |
| 여섯 갈래 → 한 결 | 따로 놀던 선이 한 다발로 모임 | 문제 섹션(앱 6개 → 하나), 학습 루프 설명 |
| 낙관(落款)과 인주 | 완성한 작품에 찍는 붉은 도장 | 액센트 색 1개. 완료 순간(복습 3/3 도장, 링크 생성, 잔디 한 칸)에만 진하게 |

**무드 키워드:** 고요한 몰입 · 밤의 도서관 · 먹과 종이 · 쌓이는 시간 · 정밀함(지도·제도) · 손의 흔적

**피해야 할 것**

| 피할 것 | 이유 · 대신 |
|---|---|
| 보라·파랑 그라디언트 SaaS 룩, 네온 글로우 남발 | 조사 3-3: 겉모양만 베낀 다크 UI는 공허함. 대신 **2색(먹·종이) + 인주 1색** |
| 유리 효과를 모든 카드에 | 블러는 떠 있는 층(팔레트·내비·펜 툴바)에만 |
| 귀여운 마스코트·이모지·게임 배지 | 대학원생까지 대상. 보상은 도장·잔디·결 무늬처럼 "기록"으로 |
| 편집 중 애니메이션 | 리더 결정·연구 공통 결론. 필기·타이핑 중에는 모션 0 |
| 랭킹·경쟁 색(빨강 경고)으로 압박 | 성장 중심(D8). 위험색은 마감 임박 등 정말 필요한 곳에만 |
| 꾸미기 기능 과잉(노션식) | "꾸미기 0분". 기본 상태가 이미 완성된 화면이어야 함 |

## 4. 타이포그래피 (Google Fonts 무료 글꼴만)

| 역할 | 글꼴 | 굵기 | 쓰는 곳 | 고른 이유 |
|---|---|---|---|---|
| 한글 디스플레이 | **Hahmlet** (가변 100–900) | 500·600·800 | 워드마크, 섹션 제목, 숫자가 아닌 큰 글자 | 현대적인 한글 명조. 가변 굵기로 키네틱 타이포(200→800) 가능 |
| 한글 본문·UI | **Noto Sans KR** (가변 300–800) | 400·500·600 | 본문, 버튼, 앱 UI 전체 | 한글 힌팅·자형 안정성 최고, 유니코드 구간별로 잘게 나눠 받음 |
| 영문 디스플레이 | **Fraunces** (가변, opsz·wght, 이탤릭) | 200·300 이탤릭, 500 | *gyeol*, D-6·13 같은 큰 숫자, 단계 번호 01–04 | 광학 크기(opsz) 축으로 크게 쓸 때 섬세함. Hahmlet과 같은 명조 계열 |
| 숫자·모노 | **JetBrains Mono** (300–600) | 300·400·500 | 타이머 25:00, 토큰 이름, 메타 라벨 | 고정폭이라 초가 바뀌어도 흔들리지 않음, 0에 빗금 |

로딩: `css2?…&display=swap` 한 줄로 4종을 받는다(`preconnect` 포함). 앱(PWA)에서는 같은 파일을 서비스 워커가 캐시해 오프라인에서도 같은 글꼴이 나와야 한다(구현은 기술 설계 쪽).

**유동 크기 스케일 (clamp)**

| 토큰 | clamp 값 | 375px | 1440px | 행간 | 자간 |
|---|---|---|---|---|---|
| `--fs-mega` | `clamp(9rem, 4rem + 30vw, 26rem)` | 177px | 416px | 0.86 | −6% |
| `--fs-display` | `clamp(2.75rem, 1.4rem + 5.6vw, 6.5rem)` | 44px | 103px | 1.04 | −4.5% |
| `--fs-h1` | `clamp(2.25rem, 1.3rem + 3.6vw, 4.5rem)` | 36px | 72px | 1.18 | −3% |
| `--fs-h2` | `clamp(1.625rem, 1.2rem + 1.7vw, 2.5rem)` | 26px | 40px | 1.2 | −3% |
| `--fs-h3` | `clamp(1.1875rem, 1.05rem + .6vw, 1.5rem)` | 19px | 24px | 1.3 | −3% |
| `--fs-lg` | `clamp(1.0625rem, 1rem + .35vw, 1.3125rem)` | 17px | 21px | 1.75 | −1% |
| `--fs-md` / `sm` / `xs` / `2xs` | 16 / 14 / 12 / 11px (고정) | — | — | 1.7 / 1.6 / 1.5 | −1% / 0 |

**한글 규칙**
1. 본문 자간 −1%, 제목 −3%, 디스플레이 −4.5~−6%. 한글에 양수 자간 금지(영문 대문자 라벨 +12%만 예외).
2. `word-break: keep-all` + `overflow-wrap: break-word`: 단어 중간에서 줄을 바꾸지 않는다.
3. 제목은 `text-wrap: balance`, 문단은 `text-wrap: pretty`. 한 줄 최대 36em(약 34자).
4. 본문 행간 1.7, 앱 UI 1.5. 한글은 영문보다 행간을 0.1~0.15 더 준다.
5. 숫자는 `tabular-nums`, 타이머·카운터는 모노체만 쓴다.

| `--ease-std` | `cubic-bezier(.2,0,0,1)` | 색·배경 |
| `--ease-spring` | CSS `linear()` 26점 근사 (오버슈트 약 16%) | 도착, 배지·노드 팝, 잔디 한 칸 |
| Motion 스프링 | snappy `{stiffness:420, damping:34}` · gentle `{170, 26}` · bouncy `{520, 22}` | 앱 컴포넌트(architecture 8장 Motion 12) |

**순차 등장:** 앱 목록 40ms, 마케팅 블록 70ms, 헤드라인 줄 90ms 간격. 최대 8개까지만 순서대로, 나머지는 함께. 앱 안에서는 총 400ms 이하, 세션당 첫 등장 한 번만. 움직임은 `transform`·`opacity`만 쓴다(레이아웃 속성 금지).

**모션 예산:** 연출은 랜딩·온보딩·오늘 화면·집중 모드·완료 순간에만. 노트 편집기·필기 캔버스·그래프 끌기 중에는 0. WebGL·캔버스 루프는 화면 밖, 탭 숨김, 팔레트·집중 모드가 열리면 멈춘다(목업에 구현됨).

**화면 전환 (View Transitions):** 공간 이동은 크로스페이드 200ms, 카드→페이지 확장은 공유 요소 420ms. 테마 전환은 토글 버튼에서 퍼지는 원형 리빌 680ms. 기기별 레이아웃 전환은 **양쪽 모두에서 보이는 카드에만** `view-transition-name`을 붙여 560ms 동안 모양을 바꾸고, 끝나면 이름을 지운다(목업에 구현됨). 미지원 브라우저는 즉시 전환.

**동작 줄이기 대체:** OS `prefers-reduced-motion` 또는 앱 설정 '모션: 끔'이면 모든 transition 0초, keyframe은 1ms로 끝 상태만 보이고, 캔버스는 정지 프레임 1장, 스크롤 연동 그림은 완성 상태, 카운터는 최종값, 로더는 생략한다. 앱 설정 3단계 중 '절제'는 opacity만 150ms 이하. (목업 검증 중, 이 규칙을 `1ms`로 두면 너비 변화까지 전환되어 레이아웃 측정이 틀어지는 버그를 발견해 `0s`로 고쳤다.)

## 목업 검증 기록

- **도구:** 데스크톱 앱 내장 브라우저(`mcp__Claude_Browser__*`). 이 브라우저는 `file://`를 열 수 없어 `.claude/launch.json`에 로컬 정적 서버(`python3 -m http.server 4173 --bind 127.0.0.1 --directory team`)를 등록해 열었다. 1440px 폭은 패널보다 넓어서 `team/logs/view.html`(1440×900 iframe을 축소해 보여 주는 검증용 페이지)로 확인했다.
- **확인한 폭:** 375×812, 768×1024, 1440×900 (각 폭에서 히어로 → 문제 → 루프 4단계 → 오늘 화면(폰·태블릿·데스크톱·창에 맞춤) → 커맨드 → 디자인 시스템 → 푸터를 스크린샷으로 확인), 다크·라이트 두 테마.
- **결과**
  - 가로 스크롤: 375·768·1440 모두 `scrollWidth = innerWidth`. 375px에서 좌우 여백 16px, 화면 밖으로 나간 요소 0개.
  - 콘솔 에러: 0건(일반 로드, 모션 끔 로드, 기기 전환 4회, 테마 전환 2회, 팔레트 실행, 집중 모드 완료까지 실행).
  - 기능: ⌘K/Ctrl+K 열기, "물리 25분" 해석 → Enter → 전체 화면 집중(데모 ×60) → 종료 → 카드 3장 → 도장 → Esc 닫기, 포커스 복귀 확인. 초성 "ㅇㅌㄹㅍ" 검색 확인. 미니 집중 10초 데모 완료 → 잔디 +1 → W5 확인. View Transitions 이름 정리 확인. 키보드 Tab 포커스 링(인주 2px) 확인.
  - 고친 문제: 동작 줄이기 시 `transition 1ms` 때문에 기기 프레임 크기 측정이 틀어지던 버그(→ `0s`), 컨테이너가 자기 자신을 쿼리하던 벤토 배치, 폰에서 미니 그래프가 손글씨를 가리던 문제, 히어로 "결" 글자와 스크롤 안내의 겹침, '한 결' 칩 아이콘 겹침, 카드 비행 연출이 끝난 뒤 흐릿하게 남던 문제.
- **남은 문제 · 한계**
  - 검증 중 브라우저 패널이 숨겨져 있어 화면 갱신이 초당 1회 정도로 제한됐다. 그래서 **60fps 부드러움은 눈으로 확인하지 못했다.** 정적 배치, 끝 상태, 로직, 에러는 확인했다. 모션 품질은 사용자가 실제 브라우저에서 한 번 봐 주는 것이 필요하다.
  - `prefers-reduced-motion`은 OS 설정을 바꿀 수 없어 같은 규칙을 쓰는 앱 설정 '모션: 끔'으로 대신 검증했다.
  - 첫 방문은 Google Fonts(한글 4종) 내려받기 때문에 인트로가 최대 1.6초 기다린다(이후 캐시).
  - 한글 호환 자모(ㅇㅌㄹㅍ)는 글꼴에 따라 작게 보일 수 있다.
