| 6 | **Loopnote** (루프노트) | 학습 루프를 이름에 그대로 | 콘셉트가 즉시 전달 | 평범함 |

**1순위 추천: 결 (GYEOL)**
- 태그라인: **"쓰고, 잇고, 남긴다 — 공부가 한 결로."** (영문: *Write. Link. Remember.*)
- 이유: ① 핵심 가치 '연결'을 한 글자에 담음 ② '나의 결'(학습량이 쌓여 자라는 생성형 무늬)이 홈 화면·로고·학기 결산까지 하나의 시각 언어가 됨 ③ 로고는 한글 '결' + 소문자 `gyeol` 병기로 발음 문제 완화.
- 확인 필요: 도메인·상표 사용 가능 여부 (사용자 결정 사항).

## 2. 비전과 핵심 콘셉트

**비전:** 학생이 수업에서 쓴 한 줄이 정리되고, 연결되고, 기억으로 남을 때까지 **앱 하나 안에서 한 바퀴** 돌게 한다.

### 학습 루프

**① 쓰기** (필기·PDF·녹음) → **② 정리** (블록·템플릿·수식) → **③ 연결** (`[[링크]]`·백링크·그래프) → **④ 복습** (카드·FSRS·시험 모드) → **⑤ 집중** (타이머·플래너·잔디) → 다시 ①

- 루프가 닫히는 지점: 집중 세션이 끝나면 '다음 할 일'로 오늘 수업 노트 또는 복습 큐가 제시되고, 복습에서 막힌 카드는 원본 필기로 돌아가 다시 쓰기·정리로 이어진다.
- 오늘 화면은 루프의 '현재 위치'를 보여준다: 지금 수업(①) · 미정리 노트(②) · 미해결 링크(③) · 복습 n장(④) · 남은 목표 시간(⑤).

### 지금의 문제: 학생 한 명이 쓰는 앱 6개

| 단계 | 지금 쓰는 앱 | 앱 사이에서 생기는 손실 |
|---|---|---|
| 쓰기 | 굿노트·노타빌리티 | 필기는 PDF 안에 갇혀 검색·연결 안 됨 |
| 정리 | 노션 | 필기를 다시 타이핑, 복붙 |
| 연결 | 옵시디언 | 별도 볼트, 손글씨는 못 넣음 |
| 복습 | Anki·퀴즐렛 | 카드를 손으로 다시 만듦, 원본 노트와 끊김 |
| 집중 | 열품타·Forest | 공부한 시간이 어떤 과목·노트였는지 모름 |
| 일정 | 에브리타임 시간표·캘린더 | 수업·과제·시험이 노트와 따로 놂 |

### 결이 전환을 없애는 5가지 장치

| 장치 | 내용 | 없어지는 전환 |
|---|---|---|
| **① 한 노트, 여러 재료** | 텍스트 블록·필기 블록·PDF 페이지가 한 문서 안에 섞임 | 굿노트 ↔ 노션 |
| **② 무엇이든 링크** | 노트·블록·손글씨 영역·PDF 페이지·카드·일정이 같은 ID 체계. `[[ ]]` 하나로 연결 | 노션 ↔ 옵시디언 |
| **③ 제자리 변환** | 문장·잉크 선택 → 카드 / 날짜 → 일정. 복붙 없음 | 노트 ↔ Anki |
| **④ 과목이 축** | 시간표 수업 = 과목 = 색 = 노트 묶음 = 카드 덱 = 통계 분류. 한 번 등록하면 앱 전체가 정렬 | 시간표 ↔ 노트 |
| **⑤ 맥락 있는 집중** | 타이머가 '지금 열린 과목·노트'에 시간을 기록하고, 휴식 때 그 과목 카드를 보여줌 | 열품타 ↔ 노트·Anki |

**신뢰 약속 (포지셔닝 문구):** 무료 · 로컬 우선 · 언제든 꺼낼 수 있음 — "내 공부 기록은 내 기기에." 조사상 학생의 구독 피로·데이터 유실 불안이 크다(research §2 P5·P8).

## 3. 페르소나

|---|---|---|---|---|
| 소속 | 기계공학과 3학년 | 경영학과 2학년 | 고3 수험생 | 인지과학 석사 2년차 |
| 기기 | 아이패드 + 애플펜슬 | 맥북 (타이핑 위주) | 갤럭시 폰 + 탭(S펜) | 27인치 모니터 + 맥북 |
| 지금 쓰는 앱 | 굿노트, Anki, 에타 | 노션, 구글 캘린더 | 열품타, 손 오답노트 | 옵시디언, Zotero, PDF 리더 |
| 가장 큰 불편 | PDF 필기 후 다시 안 봄. 시험 직전 몰아치기 | 노션은 예쁘지만 복습이 안 되고 마감이 흩어짐 | 오답노트를 써도 다시 안 봄, D-day 압박 | 읽은 논문이 서로 연결되지 않고 흩어짐 |
| 핵심 기능 | PDF 필기, 잉크 링크, 수식 카드 | 블록·템플릿, D-day, 그래프 | 순공 타이머, 오답 카드, 시험 모드 | PDF 인용, 백링크, 캔버스 |

**하루 시나리오**

- **P1 도윤 (태블릿·펜)**
  - 09:00 열역학 강의실. 오늘 화면의 '지금 수업' 카드를 탭하자 교수님 PDF가 과목 노트로 펼쳐지고, 슬라이드 위에 바로 필기한다.
  - 핵심 공식을 올가미로 감싸 `[[엔트로피]]`로 링크. 지난주 노트의 같은 개념과 그래프에서 이어진다.
  - 공강 시간, 손으로 쓴 공식 2개를 올가미로 감싸 카드로 보낸다. 밤 도서관에서 25분×4 집중, 휴식마다 카드 3장.
- **P2 서연 (노트북·타이핑)**
  - 마케팅원론 수업 중 코넬 템플릿으로 타이핑. `/표`, `/토글`, 단축키로 손을 키보드에서 떼지 않는다.
  - `[[STP]]` 링크를 걸다가 그래프에서 통계학 노트 '표본 추출'과 이어진 걸 발견한다.
  - `⌘K` → "과제 추가 금요일 23:59" → 오늘 화면 D-day 목록에 정렬된다. 주말엔 GPA 계산기로 목표 학점을 역산.
- **P3 지민 (폰 + 태블릿)**
  - 등교길 폰으로 어제 만든 오답 카드 20장을 복습한다.
  - 야간 자율학습 때 순공 스톱워치를 켜면 오늘 잔디가 짙어지고 홈의 결 무늬가 자란다.
  - 모의고사 틀린 문제를 사진으로 찍어 오답 템플릿에 넣고 원인(개념/계산/실수)을 태그. 6월 모평 시험 모드가 하루 복습량을 정해준다.
- **P4 현우 (대화면 데스크톱)**
  - 오전: 논문 PDF에서 하이라이트 → '노트로 인용'. 인용 블록이 원문 페이지 링크를 유지한다.
  - `[[작업기억]]` 개념 노트에 논문 5편의 백링크가 쌓이고, 우측 패널 로컬 그래프로 빈 연결을 찾는다.
  - 오후: 캔버스 보드에 논문 노트를 배치하고 화살표로 선행연구 구조도를 그린다. 저녁엔 50분 딥워크 2회, 앰비언트 '빗소리'.

## 7. 핵심 사용자 흐름

**흐름 1 — 수업 → 필기 → 카드 (P1, 태블릿)**
1. 오늘 화면 '지금 수업: 열역학 09:00–10:15' 카드를 탭한다.
2. 강의 PDF를 가져오면 과목 노트에 붙어 페이지 필기 모드로 열린다.
3. 펜으로 필기하고, 핵심어를 올가미로 감싸 이름을 붙이면 `[[엔트로피]]` 링크가 된다 (W1).
4. 수업 후 필기 블록 아래 '요약'에 3줄을 쓰고, 손으로 쓴 공식 2개를 올가미로 감싸 '카드로' 보낸다 (W4).
5. 오늘 화면에 '내일 복습 2장'이 뜬다. 다음 날 카드에서 막히면 '원본 보기'로 그 PDF 페이지로 간다.

**흐름 2 — 집중 세션 (공통)**
1. `⌘K` → "열역학 25분" 또는 집중 탭에서 과목·노트(최근 기본값)와 25/5를 고른다 (W6).
2. 숨 고르기 연출 후 타이머와 할 일 한 줄만 남는다 (W3).
3. 휴식 종이 울리면 방금 과목의 카드 3장이 펼쳐진다 (W5, 넘겨도 됨).
4. 4세트 후 긴 휴식. 종료 시 과목별 시간이 쌓이고 잔디·결 무늬가 갱신된다.

**흐름 3 — 시험 대비 (P3, P2)**
1. 플래너 → 시험 추가: 과목, 날짜, 범위(노트·태그 선택).
2. 오늘 화면에 D-day 카드와 범위 내 미복습 카드 수가 표시된다.
3. (v1) 시험 모드를 켜면 범위 카드 일정이 시험일 전으로 압축되고 하루 목표 장수가 정해진다 (D5).
4. 매일 오늘 화면에서 '복습 n장 → 집중 1세트'를 이어서 한다.
5. (v1) 시험 후 성적을 입력하면 학점 계산기에 반영된다.

**흐름 4 — 논문 읽기와 연결 (P4, 데스크톱 · 주로 v1)**
1. 노트 공간에 논문 PDF를 끌어놓으면 '논문 리딩' 템플릿 노트가 같이 생긴다.
2. PDF 하이라이트 → '노트로 인용': 인용 블록이 원문 페이지 링크를 유지한다 (C5).
3. 개념에 `[[작업기억]]`을 걸면 우측 패널 백링크·로컬 그래프에 다른 논문 노트가 보인다.
4. 그래프에서 묶음을 골라 캔버스 보드로 보내고, 화살표로 선행연구 구조를 그린다 (C4).
5. 결과를 마크다운으로 내보내 논문 초안에 쓴다.

**전제:** 서버·계정·유료 서비스 없이 브라우저 안에서 도는 로컬 우선 PWA. AI·동기화·협업은 MVP 밖.
**MVP 범위:** §4의 MVP 27개. MVP 한 문장 정의 = "한 과목으로 **쓰기→정리→연결→복습→집중** 한 바퀴가 다른 앱 없이 끝까지 돈다."

| 7 | 링크 | `[[` 자동완성, 없는 이름은 새 노트 생성, 대상 노트 백링크 즉시 표시, 노트 이름을 바꾸면 모든 링크가 갱신된다. 손글씨 영역(잉크 앵커)도 링크 대상이 된다. |
| 8 | 그래프 | 노트 1,000개·링크 5,000개 샘플에서 그래프가 2초 안에 그려지고, 끌기·확대가 데스크톱 60fps, 태블릿 30fps 이상이다. |
| 9 | 복습 | `질문 :: 답`, `{{빈칸}}`, 텍스트 선택→카드, 필기 올가미→카드로 만든 카드가 큐에 들어가고, 4버튼 평가 후 FSRS로 다음 복습일이 계산되며, 카드에서 원본 위치로 한 번에 이동한다. |
| 10 | 집중 | 남은 시간은 시각 기준으로 계산되어 백그라운드 탭에서 돌아오거나 화면이 꺼졌다 켜져도 25분 기준 오차 ±1초 이내다. 탭이 열려 있으면 종료 소리와 (허용 시) 알림이 오고, 집중 모드는 화면 꺼짐 방지를 요청한다. 세션은 선택한 과목에 기록되어 잔디에 반영되고, 휴식 때 그 과목 카드 3장이 제시된다. |
| 11 | 과목 축 | 시간표에 과목을 등록하면 같은 색이 노트·그래프·덱·통계·D-day에 적용되고, 수업 시간에 오늘 화면 '지금 수업' 카드를 탭하면 그 과목 노트가 열린다. |
| 12 | 팔레트·검색 | `⌘K`/`Ctrl+K`가 어느 화면에서나 열리고, 블록 1만 개 데이터에서 제목·본문·PDF 텍스트·카드 검색 결과가 100ms 안에 나온다. |
| 13 | 반응형 | 360·390px(폰), 768·1024px(태블릿 세로·가로), 1280·1440·1920px(데스크톱)에서 §6 내비게이션으로 바뀌고 가로 스크롤·잘림이 없다. 태블릿 회전·분할 화면에서도 편집 상태가 유지된다. |
| 14 | 데이터 주권 | 전체 데이터를 zip(마크다운+JSON+원본 첨부)으로 내보내 다른 브라우저에서 가져오면 노트·필기·링크·카드 일정이 같게 복원된다. 설정에 저장 용량·마지막 백업일이 보이고, 7일이 지나면 백업 알림이 뜬다. |
| 15 | 품질 | 캐시 후 오늘 화면이 1.5초 안에 보이고, Lighthouse 성능·접근성 90점 이상, 주요 동작 키보드 조작 가능, 본문 대비 WCAG AA, '동작 줄이기' 설정 시 연출 모션이 꺼진다. |

## 9. 범위 밖과 리스크

### 하지 않을 것 (MVP 기준)

| 항목 | 이유 / 대안 |
|---|---|
| 계정·로그인·클라우드 동기화 | 서버·비용 필요. 백업 zip으로 기기 이동, v2에서 선택형 동기화 |
| AI 기본 탑재 | 키·비용·개인정보 문제. v2에서 사용자가 켜는 선택 기능, 키는 서버에만 |
| 실시간 공동 편집·스터디 그룹·SNS 피드 | 복잡도 대비 MVP 가치 낮음. v2 |
| 네이티브 앱(앱스토어·플레이스토어) | PWA 설치로 대체 |
| 다른 앱·사이트 차단, 화면 꺼진 상태의 푸시 알림 | 웹 권한 밖·푸시 서버 필요. 집중 화면 + 화면 꺼짐 방지 + (v1) 탭 이탈 기록으로 대체 |
| 굿노트·노션 원본 파일 가져오기 | 포맷 비공개·변동. PDF·마크다운 경로만 지원 |

### 주요 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| **범위 폭발** — 6개 앱을 한 번에 대체하려다 전부 어중간해짐 | 높음 | MVP는 '루프 한 바퀴'에 집중, 모듈마다 핵심 20%만. 완료 기준 15개로 범위를 고정 |
| **웹 필기 품질** — 지연·필압·손바닥 처리가 굿노트보다 떨어지면 P1·P3 이탈 | 높음 | 개발 1주차에 iPad Safari·S펜 필기 지연 시제품으로 먼저 검증, 실패 시 렌더링 전략 교체 (architecture 참고) |
| **브라우저 저장소 소실** — Safari는 오래 방문하지 않은 사이트의 저장소를 지울 수 있고(홈 화면 앱은 예외), 사용자가 캐시를 지우면 데이터가 사라짐 | 높음 | 홈 화면 설치 유도, 영구 저장 권한 요청, 백업 알림(기준 14), 지원 브라우저에서 로컬 폴더 저장 |
| **연출 vs 성능** — 수상작급 모션이 필기·그래프 프레임과 배터리를 깎음 | 중간 | 모션 예산: 편집 화면은 정적, 연출은 전환·완료·홈에만. 저사양에서 자동 축소 |
| **한글 IME + 블록 에디터** — 조합 중 글자 깨짐은 한국 사용자에게 치명적 | 중간 | 에디터 엔진 선택 기준에 한글 조합 테스트 포함, 기준 6을 자동화 테스트로 |

### 사용자 결정이 필요한 점

1. 이름: '결' 확정 여부 (도메인·상표 확인 포함).
2. 1순위 기기: 아이패드+펜 필기 경험을 MVP 성능 목표의 기준으로 삼을지.
3. 녹음–필기 싱크(A5): v1 제안. MVP로 당길지.
4. AI 방향: ① 아예 제외 ② 사용자 본인 키 ③ 운영자 서버 — v2 설계 방향.
5. 잉크 링크(A4·W1): 기획은 시그니처 연출이라 MVP, 기술 설계서는 2차. 리더 조율 필요 (기획 제안: MVP는 '올가미 → 이름 입력' 단순판만).
