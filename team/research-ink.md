# 필기 앱 비교: 결이 '부족함 없음'에 닿으려면

작성: 손글씨 설계자 · 2026-10-17 · 바탕: `team/m3-brief.md`, 공식 문서·앱 스토어 설명·신뢰할 만한 리뷰(맨 아래 출처)

> **한 줄:** 결은 기능 수로 굿노트를 이기지 않는다. **학생이 매일 쓰는 20가지를 빠짐없이 넣고, 다른 앱이 화면에 늘어놓는 것을 펜·손가락·⌘K 뒤로 숨긴다.** 그리고 다른 앱에 없는 연결(테이프 → 떠올리기 → 복습 카드, 시간표 → 수업 노트, 잉크 → 별)로 이긴다.

---

## 0. 범위 · 읽는 법

- **비교한 앱:** 굿노트 6(굿), 노타빌리티(노), 노트쉘프 3(쉘), 애플 메모 + Quick Note(애), 노션(션), 옵시디언(옵), Flexcil(플), Nebo(네, 지금 이름은 MyScript Notes).
- **표의 앱 표시:** 공식 문서·앱 스토어 설명·리뷰로 확인한 것과 널리 알려진 것만 적었다. 표에 없다고 그 앱에 기능이 없다는 뜻은 아니다.
- **중요도:** 학생(고등학생·대학생, 아이패드 + 펜)이 수업·복습에서 얼마나 자주, 얼마나 아쉽게 찾는지를 기준으로 했다.
  - 상: 없으면 다른 앱으로 간다.
  - 중: 자주 쓰지만 대신할 길이 있다.
  - 하: 일부만 쓴다.
- **결 열:**
  - **M3:** 이번 마일스톤에 넣는다.
  - **있음:** M2까지 이미 있다.
  - **나중:** 몇 번째 마일스톤에서 넣을지 적었다.
  - **안 함:** 이유를 적었다.

## 1. 앱 한눈에

| 앱 | 성격 | 학생이 고르는 이유 | 결이 배울 것 | 결이 피할 것 |
|---|---|---|---|---|
| 굿노트 6 | 종이 노트북 흉내 + PDF | 펜 느낌, 폴더 정리, 템플릿·스티커, 테이프, Study Sets(플래시카드) | 테이프(가리개), 긁어 지우기, 두·세 손가락 되돌리기, 녹음 다시 보기 | 위쪽 도구 막대가 늘 보인다. 메뉴 단계가 깊다 |
| 노타빌리티 | 강의 녹음 + 필기 | **녹음과 필기 싱크**(글씨를 누르면 그때 소리), 전사, Learn(퀴즈·카드) | 획마다 시각을 남기는 구조(결은 이미 `t`를 저장) | 구독 벽, AI 기능이 화면을 채운다 |
| 노트쉘프 3 | 꾸미기 + 필기 | 템플릿 200여 개, 문구점(스티커·장식 테이프), 녹음, 태그 | 템플릿 선택이 그림 위주다 | 장식 요소가 공부 화면을 어지럽힌다 |
| 애플 메모 | 시스템 메모 | 어디서나 Quick Note, Smart Script(글씨 다듬기, 긁어 지우기), 녹음·전사, Math Notes | **도구 팔레트 자동 접힘**, 가장자리로 끌어 옮기기, 펜만 쓰기 | 공부 흐름(복습·시험)이 없다 |
| 노션 | 글·데이터 블록 | 정리·공유·템플릿, 팀 과제 | `/` 블록, 링크 | 손글씨가 없다. 오프라인은 앱에서만 된다 |
| 옵시디언 | 로컬 마크다운 | 로컬 파일, 백링크, 그래프, Canvas, 플러그인 | 로컬 우선, 명령 팔레트, 그래프 | 처음 설정이 무겁다. 손글씨는 플러그인 몫이다 |
| Flexcil | PDF 공부 | 펜 **제스처**로 형광·선택, PDF와 노트 나란히, 잘라 온 글이 원문과 이어진다 | 펜 제스처를 도구 바꾸기 대신 쓰기 | 제스처 종류가 많아 익히기 어렵다 |
| Nebo | 손글씨 인식 | 실시간 글자 변환, 긁어 지우기·줄 긋기·띄기·붙이기 제스처 | **긁어 지우기**의 판정 기준 | 인식 위주라 자유 필기가 답답하다 |

## 4. 결이 이길 곳

1. **조용함:** 화면에 늘 있는 것은 '뒤로'와 도구 칸(쓰는 동안에는 구슬 하나)뿐이다. 다른 앱은 도구 막대 + 탭 + 제목 줄 + 쪽 번호를 늘 보여 준다.
2. **떠올리기 고리:** 테이프(M3) → 헷갈린 테이프만 다시 붙이기(M3, 결정 필요) → 테이프 = 복습 카드(M4). 굿노트는 테이프와 Study Sets가 따로 논다(연습 모드에서 테이프를 쓸 수 없다는 요청이 있다).
3. **수업과 이어짐:** 시간표 → 오늘 수업 노트(코넬 틀) → 지도 별. 다른 필기 앱에는 시간표가 없다.
4. **잉크가 별이 된다:** 노트를 닫을 때 그 노트의 별이 조용히 밝아진다. 기록이 쌓이는 것이 하늘로 보인다.
5. **로컬 우선 · 구독 없음:** 노타빌리티·굿노트의 AI·동기화는 구독이다. 결은 기기 안에 남고 백업 파일로 옮긴다.

## 5. 웹(PWA)이라서 생기는 제약 → 설계에 반영한 것

| 제약 | 근거 | 설계 반영 |
|---|---|---|
| 펜 더블탭·스퀴즈를 못 받는다 | 웹 API 없음(확인한 범위) | 길게 누르기 둥근 메뉴, 두 손가락 탭, 키보드 단축키가 대신한다 |
| 펜 호버는 일부 기기만 | WebKit 엔지니어가 펜 호버 이벤트는 이미 보낸다고 답했다. 호버 중 기울기·회전은 빠진다는 보고가 있다 | 호버는 '되면 쓰는' 덤이다(펜 끝 점 미리보기, 구슬 가까이 오면 펴기). 호버가 없어도 모든 기능이 된다 |
| 글 칸에 펜을 대면 Scribble이 글자로 바꾼다 | 애플 Scribble 안내 | 메모: 글 칸 위는 Scribble(손글씨 → 글자)로 두고, **그 밖의 빈 곳**에 펜을 대면 잉크 칸으로 바꾼다(설계 8장) |
| Scribble이 켜져 있으면 포인터 이벤트가 끊기던 버그 | WebKit 217430(고침). 우회책은 touchmove에서 preventDefault | 잉크 면에는 `touch-action: none`과 touchmove preventDefault를 둔다(엔진 개발자 확인) |
| Safari의 pointermove 샘플링이 touchmove보다 낮다는 보고 | 애플 개발자 포럼 | `getCoalescedEvents()`를 꼭 쓴다. 엔진 개발자가 120Hz 기기에서 실측한다 |
| 길게 누르면 Safari가 글 선택·돋보기·콜아웃을 띄운다 | Safari 기본 동작 | 종이·도구 칸에 `-webkit-touch-callout: none` · `user-select: none` |
| 왼쪽 가장자리 밀기 = Safari '뒤로' | Safari 탭 모드 | 가장자리 서랍은 **홈 화면 앱(standalone)에서만** 켠다. 탭 모드에서는 쪽 번호 누르기·⌘K로 연다 |
| iOS Safari에는 진동(haptic)이 없다 | — | 손맛은 눈으로 준다(눌림 크기·스프링·작은 빛) |
