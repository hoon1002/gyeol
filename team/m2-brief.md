# M2 브리프 — 입구 (리더 작성, 2026-10-17)

## 사용자 원문
> 좋아, M2(입구: 메모·노트 편집기·링크·검색·시간표·백업) 시작해줘

## 왜 M2인가 (plan-v4-final 4-1)
첫 시험(4–6주차) 전까지 이 앱은 **빠름**으로 이겨야 한다. 1초 메모와 즉시 반영이 그 빠름이다. M2가 끝나면 학생이 실제로 매일 쓸 수 있다.

## 범위
1. **1초 메모 (별가루):**
   - 어디서든 열린다: 폰 아래 독 가운데 ＋, 태블릿·데스크톱 레일 ＋, 단축키 `n`(글 입력 중이 아닐 때), ⌘K에 문장을 치고 '메모로 저장'.
   - 글 메모, 사진 메모(카메라·파일 → assets).
   - 저장은 Enter 한 번이고, 저장하면 하늘에 별가루가 생긴다.
   - **여는 데 0.15초 이하**여야 하므로 메모 시트는 미리 마운트해 두고 지연 로드하지 않는다.
2. **별가루함:**
   - '오늘' 화면의 한 줄 '별가루 n'과 ⌘K로 연다.
   - 메모 목록에서 노트로 옮기기, 할 일(Task)로 옮기기, 보관을 한다. 카드로 옮기기는 M3다.
   - 과목은 자동 추정(lib/parser 별칭)하고, 사람이 고칠 수 있다.
3. **노트 편집기:**
   - TipTap 3(설치됨: @tiptap/react·pm·starter-kit·extension-placeholder·suggestion).
   - 글 블록 8종: 문단·제목 2단계·목록·번호 목록·체크·인용·코드·구분선.
   - **한글 입력 안전**: 조합 중에는 저장·링크 제안·단축키를 멈춘다.
   - 자동 저장은 0.6초 디바운스로 noteBodies에 한다.
   - 편집기는 노트를 열 때 지연 로드한다(첫 화면 번들 보호).
4. **링크:**
   - `[[`로 노트 제안(제목 검색), 없는 제목이면 '새 노트 만들기'.
   - 저장할 때 links 테이블을 다시 계산한다. 노트 아래에 백링크('이 노트를 가리키는 노트')를 보여 준다.
   - 지도에서는 진짜 별과 빛줄기로 보인다.
5. **검색:**
   - 노트 제목·본문·메모 전체를 대상으로 한다. 한글은 2-gram 역색인을 직접 구현한다(패키지 없이).
   - **0.1초 이하**(노트 1,000개 기준). ⌘K 결과에 섞고, 노트 화면에 검색 칸을 둔다.
   - 찾은 노트 별은 지도에서 반짝인다.
6. **시간표 넣기:**
   - 계획 화면의 주간 격자에 끌어서 수업 칸을 그린다(과목·강의실 입력). 2분 안에 끝나야 한다.
   - .ics 파일 가져오기: 매주 반복(RRULE WEEKLY) VEVENT를 수업으로, 직접 파싱한다.
   - 에브리타임 긁어오기는 하지 않는다.
   - **오늘 수업 노트:** 오늘 수업이 있으면 노트 목록 맨 위에 '오늘 ○○ 수업 노트'를 둔다. 누르면 수업 템플릿으로 만든다(classKey로 중복 방지).
7. **템플릿 2종:**
   - 수업 노트: 날짜·과목 / 핵심 / 질문 / 한 줄 요약.
   - 개념 정리: 정의 / 예시 / 헷갈리는 점 / 연결.
8. **백업:**
   - 설정 시트 '데이터' 맨 위에 '전체 내보내기'와 '가져오기'를 둔다.
   - 형식은 `.gyeol.zip`(fflate 설치됨)이다. 안에 data.json(모든 테이블) + assets/ + notes/*.md(마크다운 사본)를 넣는다.
   - 가져오기 방식은 '합치기'(같은 id면 updatedAt이 큰 쪽)와 '바꾸기'(확인 2단계)다.
   - **내보내고 다시 넣으면 그대로**여야 한다(왕복 시험).
   - 아이폰 사파리에서 홈 화면 설치를 권하는 한 줄을 둔다.
9. **첫 실행 2분 체험 = 순간 ① '성운이 태어나는 첫 밤':**
   - 빈 상태에서 열면 과목(이름·색)과 시간표를 넣게 한다.
   - 과목 하나를 넣을 때마다 그 색의 성운이 피어난다. 여섯 번째(또는 '다 넣었어요')에서 카메라가 물러나 은하 전체를 보여 준다.
   - 건너뛰기가 있다. 샘플 데이터로 시작하는 길도 둔다.

## M2에서 하지 않는 것
카드 자동 추출·FSRS·떠올리기(M3), 밤 의식의 메모 정리 흐름(M4), 음성 메모, 펜·PDF(M5).

## 완료 기준 (plan-v4-final 5장)
- 어디서든 메모 입력 가능 상태까지 0.15초 이하(키 → 입력창 포커스).
- 한글 입력 깨짐 0. 조합 중 Enter·저장·제안이 글자를 자르지 않는다. 자동 시험은 compositionstart/update/end를 흉내 내고, 실기기 확인은 사용자에게 요청한다.
- 링크가 지도에 진짜 별·선으로 보인다.
- 검색 0.1초 이하(1,000노트 합성 데이터).
- 내보내고 다시 넣으면 그대로(테이블별 개수와 해시 비교).
- 장소 이동 최장 프레임 ≤ 20ms 유지, 콘솔 오류 0, typecheck·build 통과, 첫 화면 JS 증가 ≤ 30KB(gzip). 편집기는 지연 로드한다.

## 데이터 (리더가 이미 넣음: src/db/schema.ts version 2)
- `noteBodies(noteId, doc, text, version, updatedAt)`
- `links(id, from, to|null, toTitle)`
- `memos(id, text, assetId?, subjectId?, state 'inbox'|'filed'|'archived', filedTo?)`
- `assets(id, ownerId, mime, blob)`
- notes에 `classKey`·`template`를 더했다.
- 스키마를 바꿔야 하면 리더에게 말한다(version 3으로).

## 하늘 계약 추가 (모션 개발자가 @/fx에 추가만)
- `useSkyEvent().dust({ id, subjectId? })`: 메모 저장 → 나의 자리 둘레에 별가루 한 점.
  - 별가루 수는 `setDust(n)`이고, 상한이 있어서 많아도 은은하다.
  - `fileDust(id, subjectId)`: 나누면 그 과목 성운 쪽으로 흘러간다.
- 노트 별: `useSkyStars({ notes: [{ id, subjectId, links }] })`로 지도의 과목 성운 둘레에 노트마다 별 하나(id 해시로 자리 고정)를 둔다.
  - 새 노트는 birthStar, 링크는 GL 빛줄기로 그린다.
  - 노트 1,000개·링크 2,000개에서도 활동 GPU ≤ 5ms.
- `glintNotes(ids)`: 검색 결과 별을 반짝인다.
- `bloomNebula(subjectId, color)`: 과목 성운이 피어난다(순간 ①).
- `revealGalaxy()`: 카메라가 물러나 은하 전체를 보인다(순간 ①의 끝, 2–3초, 롤 0).
- 이름과 세부는 아트 디렉터 design-m2.md에 맞추고, 바뀌면 리더에게 알린다.

## 리더 결정 (design-m2 반영, 2026-10-17)
1. 첫 실행 순서는 **과목 → 시간표 → 은하 보이기**로 한다(아트 디렉터 안 승인). 은하 전체가 처음 보이는 순간을 마지막 보상으로 둔다.
2. 샘플 표시는 스키마를 바꾸지 않고 **id 접두어 `seed-`**로 한다. 모든 샘플 행의 id가 이것으로 시작한다. '샘플 지우기'는 테이블마다 `where('id').startsWith('seed-')`로 지운다.
3. `fileDust(id, subjectId | null, to?: 'note' | 'task' | 'archive')`의 세 번째 인자를 승인한다.
4. ⌘K 결과는 8줄 고정이다(장소 2 · 노트 4 · 메모 2, 마지막 줄은 늘 '메모로 저장'). 더 많이 보려면 노트 화면 검색 칸을 쓴다.
5. 오늘 화면의 '최근' 장은 뺀다. 최근 노트는 ⌘K 빈 상태의 '최근 5'와 노트 목록이 맡는다.
