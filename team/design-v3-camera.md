# 디자인 v3 카메라: 공간 = 은하 속 장소

작성: 아트 디렉터 · 2026-10-17 · 바탕: `team/camera-brief.md`(원문·안전·성능·API), `team/design-v3-motion.md`(빛의 어휘 V1–V13·연결 지도), `team/design-v3.md` §2·§6
**이 문서가 정하는 것:** 7개 공간의 은하 속 자리, 공간 사이 비행, 별을 눌렀을 때의 접근, 첫 진입, 설정. 수치는 모두 iPad 가로 기준이고 폰은 별도 칸에 적었다.

> **한 줄:** 앱은 하나의 은하이고, 공간은 그 안의 장소다. 깊이 들어갈수록 몰입하고, 돌아오면 하늘 전체가 다시 보인다.

## 1. 장소 지도

**좌표 정의**
- 세계 좌표는 '오늘'의 iPad 가로 화면을 [0,1]²로 둔 값이다. 정적 하늘은 둘레 여백 0.15를 더한 [−0.15, 1.15]²로 굽는다(플래너가 물러날 공간).
- `focus`는 화면 가운데에 오는 세계 좌표이고, `zoom`은 오늘을 1로 본 배율이다. 보이는 폭은 1/zoom이다.
- 데이터 별(오늘의 별자리·시험 별·복습 별·노트 별)은 **세계 좌표에 고정**한다. 그래서 어느 장소에서 봐도 같은 별이 같은 자리에 있다.
- 글자 안전 구역(design-v3 §2-1)은 **화면 좌표**로 렌더러가 카메라 뒤에 적용한다. 어느 장소에서든 글자는 같은 자리, 같은 어둠 위에 놓인다.

| 공간 | 은하 속 장소 (의미) | focus (iPad) | zoom | 노출 | 보이는 구도 | 데이터 별 | 폰 focus · zoom |
|---|---|---|---|---|---|---|---|
| **오늘** (집) | 은하수 전체가 보이는 넓은 하늘. 하루 전체를 한눈에 | (0.50, 0.50) | 1.00 | 밤 100 · 낮 시간 80 | design-v3 §2 그대로. 띠가 오른쪽 위에서 쏟아진다 | 오늘의 별자리 (0.45–0.58, 0.08–0.36), 시험 별 (0.82, 0.48) | (0.50, 0.50) · 1.00 |
| **설정** | 집 안. 오늘과 같은 자리를 어둡게 | (0.50, 0.50) | 1.00 | 65 | 오늘과 같다(비행 없이 노출만 V6 450ms) | 없음 | 같음 |
| **플래너** | 조금 물러나 더 넓은 하늘. 앞날을 멀리 보는 시간의 지평 | (0.55, 0.47) | **0.88** | 80 | 띠가 작아지고 왼쪽 위 검은 하늘이 넓어진다. 여백 0.15 안에서 끝난다 | 시험 별(지평선 쪽에서 앞날을 알린다), 오늘의 별자리는 작게 | (0.50, 0.46) · 0.88 |
| **노트** | 은하 꼬리 바깥 팔의 조용한 자리. 차분한 종이의 자리 | (0.40, 0.74) | 1.40 | 55 | 푸른 꼬리 헤이즈와 성긴 별. 코어는 화면 밖(오른쪽 위)에 있다. 종이 면이 오른쪽에 뜬다 | 없음 (조용함) | (0.30, 0.62) · 1.40 |
| **복습** | 띠 몸통의 밝은 별무리 안. 카드 하나하나가 별무리의 별 | (0.66, 0.50) | 1.90 | 70 | 띠 몸통의 별 그레인과 먼지 실이 화면 오른쪽 2/3를 채운다 | 복습 별 n개: 세계 (0.80, 0.30) → (0.69, 0.62) 사선, 화면 기준 (0.77, 0.12) → (0.56, 0.73) | (0.60, 0.32) · 1.90 |
| **그래프** | 코어 옆 성운 속. 노트 별자리가 모인 생각의 성운 | (0.70, 0.36) | 2.30 | 띠 45 · 데이터 별 100 | 코어가 오른쪽 위 가장자리에서 빛을 번지고, 과목 성운 6개가 물든다 | 노트 별 54 · 선 87을 세계 (0.49–0.92, 0.15–0.57)에 고정. 화면 왼쪽 아래 글자 구역(세계 x < 0.66 · y > 0.41)은 비운다 | (0.66, 0.20) · 2.20 |
| **집중** | **내 별이 태어나는 자리.** 오늘의 별자리 바로 곁, 코어 왼쪽의 고요한 어둠 | 다음 별 자리 − 별 좌석 보정 (기본 (0.48, 0.33)) | **3.00** | 대기 60 · 실행 50 | 오늘의 별자리를 가까이서 본다(별 사이 84–192px). 코어 빛은 오른쪽 가장자리에서만 들어온다 | 새 별이 **별 좌석**(화면 (0.64, 0.42))에 온다. 오늘의 별 5개가 그 둘레에 | (0.45, 0.26) · 3.00, 좌석 (0.62, 0.30) |

- 브리프 초안의 '집중 = 암흑대 옆 어둠'은 **'내 별이 태어나는 자리'로 바꿨다.** 집중에서 태어난 별이 오늘로 돌아왔을 때 별자리 안 같은 자리에 그대로 있어야 기능과 하늘이 하나가 되기 때문이다. 어둠은 코어 왼쪽의 바깥 헤이즈가 맡는다.
- 플래너는 0.85에서 **0.88**로 바꿨다. 플래너 → 집중 비행의 배율이 3.5배(3.00 ÷ 0.88 = 3.41)를 넘지 않게 하려는 것이다.
- **별 좌석:** 무언가에 다가갈 때 그 대상이 앉는 화면 자리. iPad (0.64, 0.42), 폰 (0.62, 0.30), 데스크톱 (0.64, 0.42). 글자 안전 구역 오른쪽, 코어 빛과 독을 피한 자리다.
  - focus = 대상 위치 − (좌석 − 0.5) ÷ zoom 으로 구한다.
  - 결과가 굽힌 범위를 벗어나면 focus를 범위 안으로 끌어온다(clamp).

## 2. 비행 안무 (공간 A → B)

**깊이 순서:** 플래너 0.88 < 오늘 = 설정 1.00 < 노트 1.40 < 복습 1.90 < 그래프 2.30 < 집중 3.00

| 쌍의 종류 | 판정 | 경로 | 예 |
|---|---|---|---|
| 다가감 | zB ÷ zA ≥ 1.25 | 로그 줌으로 커지면서 평행 이동한다. 목적지가 화면 안에 있으면 그 점이 거의 제자리에 머문다(van Wijk–Nuij 경로, ρ = 1.2) | 오늘 → 집중, 노트 → 복습 |
| 물러남 | zB ÷ zA ≤ 0.8 | 다가감의 역경로 | 집중 → 오늘, 그래프 → 플래너 |
| 옆으로 | 0.8 < 비율 < 1.25, focus 거리 ≥ 0.08 | 중간에 살짝 물러났다가 다가간다. 가장 멀 때의 zoom = min(zA, zB) ÷ 1.2 | 복습 ↔ 그래프 |
| 제자리 | 같은 장소(오늘 ↔ 설정) | 비행 없이 노출만 V6 450ms | 오늘 → 설정 |

**지속시간과 이징**
- 지속시간 D = 900 + 140 × |log₂(zB ÷ zA)| + 200 × (focus 거리 × max(zA, zB)) ms, 900–1300ms로 자른다. 예: 오늘 → 집중 1150ms, 복습 → 그래프 1000ms, 집중 → 플래너 1240ms.
- 이징은 `cubic-bezier(.65,0,.35,1)`이다. 가속·감속 구간이 각각 35% 이상이다.
- 줌은 로그 공간에서, 노출은 선형 빛 공간에서 같은 진행률로 보간한다.
- 배율 변화는 한 번에 3.5배 이하이고 회전은 0이다.

| 진행 | 하늘 | 글자 · 셸 |
|---|---|---|
| t = 0 (클릭 프레임) | 비행 시작. 노출 A → B 보간 시작. 데이터 층 A 페이드아웃(0 → 0.3D) | A 내용 opacity 1 → 0 (180ms). **독·레일·상단 요소는 화면에 고정**(눈의 기준점). 독 활성 점 크로스페이드 200ms |
| 0.3D → 0.6D | 비행 한가운데. 글자 없이 하늘만 지나간다 | 비어 있음 (명사구 없음) |
| 0.6D → D | 데이터 층 B 페이드인(별이 V3로 켜지는 느낌) | B 들어옴: D − 320ms에 시작. 명사구 → 메타 → 동작, 30ms 간격, 각 290ms opacity |
| D | 도착. 시차 0, 정지 | 끝 |

**시차 층 (비행 중에만)**
- 층별 배율 = 카메라 배율 × (1 + δ × sin(π·진행률))로, 정지 상태에서는 모든 층이 같다.
- 층 사이 차이는 8% 이하다.

| 층 | 내용 | δ |
|---|---|---|
| 0 (먼 층) | 분해 안 된 별빛 · 띠 · 암흑대 · 성운 | 0 |
| 1 | 3등급 별 | +0.02 |
| 2 | 2등급 별 | +0.04 |
| 3 | 0~1등급 별 · 데이터 별 | +0.06 |
| 4 (가까운 층) | 별가루 | +0.08 |

**별 크기:** 다가가도 별은 커지지 않는다(점 크기 +15% 상한). 대신 더 밝아지고 더 많이 보인다. 보이는 등급 한계를 zoom이 2배가 될 때마다 +0.8등급씩 늘린다.

**비행 중 다시 누르면**
- **이어서 난다.** 지금 위치·로그 줌·속도에서 새 목적지로 새 D를 계산해 날아간다. 속도는 끊기지 않게 잇고(Hermite), 되감기·점프는 없다.
- 글자: 보이던 것은 지금 opacity에서 0으로 내보낸다. 중간 목적지의 글자는 보여 주지 않고, 마지막 목적지의 글자만 D − 320ms에 들어온다.
- 마지막으로 누른 곳이 이긴다.
- 지금 가는 곳을 또 누르면 무시한다.
- 비행 중 별 누르기는 무시한다. 진행률 85% 이후의 누름은 도착 직후에 처리한다.

**비행 중에는** 다른 사건(V1·V2·V5)을 대기열에 넣었다가 도착 뒤 150ms에 재생한다. 별가루는 새로 만들지 않고, 있던 것만 계속 떨어진다.

## 3. 별 누르기: 다가가서 한 줄로 보기

- 별을 누르면 그 별이 **별 좌석**에 오도록 날아간다. 왼쪽 글자 구역에는 그 별의 정보가 **명사구 1 + 메타 1 + 동작 1**로 뜨고, 보던 화면의 글은 opacity로 바뀐다.
- 닫기(× · Esc · 빈 하늘 누르기 · 뒤로)는 `back()`이다. 원래 장소로 물러나며, 비행 규칙은 2장과 같다.
- 별 누름 영역은 반지름 22px(손가락) / 14px(포인터)로, 별보다 크게 잡는다.

| 별 | 있는 곳 | 다가감 | 보이는 것 (명사구 / 메타 / 동작) | 하늘 |
|---|---|---|---|---|
| 오늘의 별 | 오늘 · 집중 | zoom × 2.4 (오늘 1.0 → 2.4) | **일반물리** / 10.16 14:05 · 25분 / 노트 열기 (그 세트에 연 노트. 없으면 동작 없음) | 그 별에 V11 반짝. 별자리 선 중 그 별의 선만 60% |
| 시험 별 | 오늘 · 플래너 | zoom × 2.4 | **일반물리 중간고사** / 10.22 · D-6 · 범위 42 / 범위 복습 | H-α 성운이 가까이 보인다. 밝기는 그대로(D-day 값) |
| 복습 별 | 복습 | 1.9 → 3.0 | **카드 앞면 한 줄**(예: 엔트로피의 정의) / 일반물리 · 내일 다시 / 이 카드 복습 | 그 별 +10% (V3) |
| 노트 별 | 그래프 | 2.3 → 3.4 | **엔트로피와 열역학 제2법칙** / 일반물리 · 링크 2 / 열기 | 그 별은 별빛 금 3.2px, 그 선만 60% (V3) |
| 나의 별 (지난 날) | 오늘 | zoom × 2.0 | **10.14** / 4세트 · 1:40 / — | 그날의 별들만 +25% |

- 별 안에서 다른 별을 누르면 옆으로 날아간다(2장 '옆으로' 규칙, 900ms).
- 별 정보에서 동작을 누르면(예: 노트 열기) 그 공간으로 이어서 난다. 예를 들어 오늘의 별 2.4 → 노트 1.4로 물러나며 옆으로 간다. `back()` 기록은 지운다.
- 하늘 사건 연결 지도의 33·44행(캡션 3초)은 **포인터 호버**에만 남긴다. 탭이나 클릭은 위의 다가가기다.

## 4. 첫 진입 안무와 카메라 (세션당 1회, 1.5초 이하)

**'내려앉기':** 살짝 먼 하늘에서 오늘의 자리로 내려앉는 동안 눈이 어둠에 익는다. design-v3-motion §4의 순서는 그대로 두고, 시작점과 길이만 바꾼다.

| t (ms) | 카메라 | 하늘 | UI |
|---|---|---|---|
| 0 | zoom 0.84, focus (0.53, 0.47) (오늘보다 조금 멀리, 정지) | 노출 55%, 0~1등급만 | 없음 |
| 0 → 1300 | 0.84 → 1.00, focus → (0.50, 0.50). 이징 `cubic-bezier(.45,0,.25,1)` (감속이 긴 내려앉기). 시차 층 δ 그대로 | 노출 55 → 100%. 2등급은 200–800ms, 3등급은 400–1100ms에 켜진다 | 명사구 500 · 메타 560 · 동작 620 (각 320ms). 셸 700 (240ms) |
| 700 → 1400 | 거의 도착 | 오늘의 별이 차례로 V3, 선은 V2를 200ms로 빠르게 | — |
| 1500 | 끝 | 별가루 생성은 1.5초부터 2초 동안 늘어난다 | — |

- 앱을 연 것은 사용자의 행동으로 친다(브리프 안전 규칙 1). 그래서 이 비행은 허용된 유일한 '누름 없는' 비행이고, 세션당 1번만 한다.
- 다른 공간 주소로 열면(예: `/focus`) 그 장소의 zoom × 0.84에서 그 장소로 내려앉는다.
- 어느 순간에 눌러도 200ms 안에 도착 상태로 건너뛴다.
- 설정이 '짧게'면 0.95 → 1.00으로 600ms. '끔'이나 동작 줄이기면 카메라를 움직이지 않고 노출만 바꾼다(끔: 600ms, 동작 줄이기: 최종 장면).

## 6. 성능 · API 메모 (모션 개발자)

- **LOD 굽기:** 앱 시작 때 L0(세계 [−0.15, 1.15]², 오늘 화면의 1×, zoom ≤ 1.3용)을 굽는다. 진입 뒤 유휴 시간에 L1(2×, 노트·복습·그래프 장소의 보이는 범위만 타일로)과 L2(3.5×, 집중 장소와 오늘의 자리·시험 별 둘레)를 미리 굽는다. 타일은 한 프레임에 4ms 이하로 쪼갠다.
- **미세 별:** 셰이더의 미세 별은 화면 px 격자가 아니라 **세계 좌표 격자**로 옮긴다. 그래야 줌해도 별이 미끄러지지 않고 늘 선명하다.
- **GPU 메모리:** 96MB 이하(L0 ≤ 32 · L1 ≤ 40 · L2 ≤ 24MB, RGBA16F 또는 RGB10A2). 굽지 않은 장소로 날아가면 L0을 확대해 보여 주고, L1이 준비되는 프레임부터 300ms 크로스페이드로 바꾼다.
- **API(브리프 그대로):** `useSkyCamera().flyTo / back / current`를 쓴다. `FieldMood preset`이 바뀌면 그 장소로 자동 비행하고, `useFieldTransition`은 비행 길이 D를 따른다. 새로 필요한 것은 추가만 한다:
  - `PLACES: Record<MoodName, CameraTarget>` (1장 표의 값)
  - `useSkyCamera().seatFocus(worldPoint, zoom)` (별 좌석 계산)
  - `getSkyStats().flights { count, p95FrameMs, maxFrameMs }`
