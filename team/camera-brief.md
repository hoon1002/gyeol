# 은하 카메라(공간 비행) 브리프 — 리더 작성, 2026-10-17

## 사용자 원문

> 아니 계속 진행해줘 / 한도가 끝날거 같으면 그때 멈춰줘
> 그리고 지금은 은하수를 보는 방향이 하나 뿐이잖아
> 그 막 누르면 은하수 가까이 갔다가 다시 나오면 다시 멀어졌다가 막 이러는거 안되나
> 진짜 클로드의 한계를 보여줘 / 디자인이랑 모션이랑 기능이랑 / 기적을 보여줘

## 콘셉트: 공간 = 은하 속 장소

앱의 각 공간은 같은 은하수 안의 서로 다른 장소이고, 이동은 그 장소로의 짧은 비행이다. 깊이 들어가면 가까워지고, 돌아오면 멀어진다. 디자인(하늘)·모션(비행)·기능(공간)이 하나의 지도가 된다.

| 공간 | 은하 속 장소 (초안, 아트 디렉터가 다듬음) | 줌 | 의미 |
|---|---|---|---|
| 오늘 | 은하수 전체가 보이는 넓은 하늘 (집) | 1.0 | 하루 전체를 한눈에 |
| 플래너 | 조금 물러나 하늘이 더 넓게 (시간의 지평) | 0.85 | 앞날을 멀리 본다 |
| 노트 | 은하 꼬리 쪽 조용한 바깥 팔 | 1.4 | 차분한 종이의 자리 |
| 복습 | 띠를 따라 밝은 별무리 안으로 | 1.9 | 카드 = 별무리의 별 |
| 그래프 | 코어 옆 성운 속, 노트 별자리가 모인 곳 | 2.3 | 생각의 성운 |
| 집중 | 암흑대 옆 고요한 어둠, 내 별 하나가 가운데 | 3.0 | 가장 깊은 곳 = 몰입 |
| 설정 | 오늘과 같은 자리, 어둡게 | 1.0 | — |

- **안쪽으로 = 가까이:** 오늘 → 복습/그래프/집중은 다가간다. 돌아오면 멀어진다.
- **별을 누르면 그 별로:** 오늘의 별·복습 별·노트 별을 누르면 그 별 쪽으로 다가가 자세히 보고(예: 그 세트의 기록, 그 카드, 그 노트), 닫으면 물러난다.

## 멀미 안전 규칙 (카메라 전용, 설계 원칙 5장에 추가)

1. **사용자가 누른 직후에만** 움직인다. 저절로 움직이는 카메라 없음(대기 중 표류 없음).
2. 회전 없음. 줌과 평행 이동만. 한 번 비행 900~1300ms, ease-in-out(가속·감속 구간이 전체의 35% 이상), 한 번의 줌 배율 변화 ≤ 3.5배.
3. 독·상단 바 같은 크롬은 화면에 고정(눈의 기준점). 글자는 비행 중 opacity로만 바뀐다(글자가 날아오지 않음).
4. 깊이감: 별을 3~5개 깊이 층으로 나눠 비행 중 미세한 시차(층 사이 차이 ≤ 8%)를 준다. 정지 상태에서는 시차 없음.
5. 설정 '공간 이동': **비행(기본) / 짧게(줌 30%만 + 크로스페이드) / 끔(크로스페이드)**. OS '동작 줄이기'면 자동으로 '끔'.
6. 비행 중 다시 누르면 현재 위치에서 새 목적지로 이어서 날아간다(되감기·점프 없음).

## 성능 규칙

- 비행 중에도 굽기 0회, 프레임 예산 데스크톱 8.3ms(120Hz) / iPad 같은 목표. 비행 중 최장 프레임 ≤ 20ms.
- 줌해도 선명해야 한다: 정적 하늘을 여러 해상도(LOD)로 미리 굽거나, 가까이 갈 장소의 고해상도 타일을 시작 후 유휴 시간에 미리 굽는다. GPU 메모리 예산 ≤ 96MB(iPad 고려).
- 밝은 별·데이터 별은 3D 점으로 그려 줌에서도 크기가 자연스럽게(별은 커지지 않고 더 밝고 많아 보이게).

## API 계약 (추가만, 기존 이름 유지)

```ts
type CameraTarget = { scene: MoodName; focus?: [number, number]; zoom?: number }
useSkyCamera(): {
  flyTo(target: CameraTarget, opts?: { duration?: number }): Promise<void>
  back(opts?: { duration?: number }): Promise<void>   // 직전 위치로 물러나기
  current: CameraTarget
}
```
- `FieldMood preset`이 바뀌면 그 공간의 장소로 자동 비행한다(useFieldTransition과 같은 타임라인: 글자 전환과 비행이 같은 프레임에 시작, 비행 길이를 따른다).
- 별을 누르면 앱이 `flyTo({ scene, focus: 별 위치, zoom })`, 닫으면 `back()`.
- 모션 수준(useMotionPrefs)과 설정 '공간 이동'을 존중한다.

## 사용량 규칙 (모든 팀원)

진행 표시를 갱신할 때마다(대략 10분마다) `mcp__ccd_session_mgmt__get_usage`로 5시간 한도를 확인한다(도구가 없으면 생략). **95% 이상이면** 지금 하던 작은 단계만 끝내고, `npm run build`가 통과하는 상태로 정리한 뒤, 남은 일을 노트에 적고 완료 보고한다. 빌드가 깨진 상태로 멈추지 않는다.
