# 은하수 디자인 탐색 브리프 (리더 작성, 2026-10-16)

## 사용자 피드백 원문 (M0 확인 후)

> 1. 화면에 적어둔 글 있지 오늘은 몇시간 집중했어요, 어제보다 몇프로 더했어요 이런거는 그냥 앱 광고화면 같아 좀 더 깔끔하게 디자인해줘 글이 굳이 그렇게 많을 필요는 없을거 같아
> 2. 그리고 지금 계속 원형을 그린듯한 느낌에 울렁거리는 효과를 쓰니까 이게 쓰는 사람들이 멀미가 날 수도 있을거 같아 지금도 좋지만 새로운 디자인도 한번 기획해줘 figma로 먼저 볼 수 있게도 해줘. 내가 생각한건 그냥 은하수가 쏟아지는 듯한 아름다운 디자인 있지 이거 가능할까 그냥 보자마자 우와 아름답다.. 이런 소리가 절로 나오도록 그냥 클로드코드의 모든 힘을 쏟아버려
> 3. 디자인 보고 수정할지 말지 결정해보자

## 이번 단계의 목표

**보자마자 "우와, 아름답다"가 나오는 '은하수' 디자인 방향**을 만들어 Figma와 실제로 움직이는 시제품으로 보여 준다. 사용자가 보고 앱에 반영할지 결정한다. **M0 앱 코드(src/의 기존 파일)는 이번 단계에서 고치지 않는다.**

## 리더가 정한 방향 (출발점, 아트 디렉터가 다듬는다)

1. **장면:** 밤하늘에 은하수가 화면 위쪽에서 아래쪽으로 대각선으로 쏟아진다. 따뜻한 금빛·살구빛 은하 중심 → 짙은 먼지띠(암흑대) → 푸르스름한 외곽. 수만~수십만 개의 별(밝기·크기는 멱함수 분포, 색은 별의 온도), 희미한 성운 안개. 사진처럼 깊고, 그림처럼 정돈된.
2. **"쏟아진다":** 은하 띠에서 아주 느리게 별가루가 흘러내린다(별의 폭포). 빠르지 않고, 화면 전체가 움직이지 않는다.
3. **멀미 없는 움직임 (전정기관 안전, 필수):**
   - 금지: 화면 전체의 회전·확대·큰 패럴랙스, 왜곡·울렁임(등고선 휘기, 물결 왜곡), 동심원 고리, 맥박처럼 커졌다 작아지는 효과, 빠른 이동.
   - 허용: 별 하나하나의 반짝임(밝기만, 낮은 진폭·느린 주기), 느린 별가루 낙하(초당 12px 이하), 포인터 근처 별이 살짝 밝아짐(위치 이동 없음), 화면 전환은 크로스페이드 + 아주 약한 밝기 변화, 드문 유성(분당 1회 이하, 짧고 작게, 끌 수 있음).
   - '동작 줄이기'면 완전히 정지한 한 장면. 그래도 아름다워야 한다.
4. **글 다이어트:** 광고처럼 들리는 문장(감탄, "어제보다 18% 더", "2시간 10분 집중했어요" 같은 자랑형 문장)은 없앤다. 화면당 읽는 글은 거의 없게: 짧은 명사구 하나(예: "일반물리"), 작은 메타 한 줄(예: "09:00 – 10:15"), 동작 버튼 하나. 숫자는 꼭 필요할 때만, 작게.
5. **데이터가 하늘이 된다:** 숫자 대신 하늘이 말한다. 예) 집중 25분마다 별 하나가 태어나 밝아진다, 노트 연결은 별자리, 복습은 별이 다시 빛나는 것. '나의 결'은 '나의 은하'로. (결 = 은하수의 결, 브랜드 이름은 그대로 '결')
6. **기준 화면:** iPad 가로 1180×820 + 폰 390×844. 데스크톱 1440×900도.
