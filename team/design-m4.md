# 디자인 M4: 기억 엔진 — 조용한 화면

작성: 아트 디렉터 · 2026-10-17 · 바탕: `team/m4-brief.md`, `plan-v4-final.md` 3-2 · 4-1 · 4-3(순간 ③ · ④), `design-quiet.md`(글 1줄 · 아이콘 · 툴팁 · 첫 회), `design-ink.md` 7장(테이프), `design-m1.md`(사건 · 글 구역 · 시간 띠), `design-m2.md` 4-3(노트 별)

> **한 줄:** 앱이 "무엇을 얼마나"를 계산하고, 화면은 **오늘 몫의 숫자 하나**만 보인다. 밀린 양은 어디에도 나오지 않는다. 하루치를 끝낼 때마다 하늘에 선이 하나 그어진다.

**누가 무엇을:** 앱 A → 1 · 2 · 3 · 5장. 앱 B → 4 · 7 · 8장. 손글씨 → 1-6 · 3-4. 모션 → 5 · 6장. **모두 0장과 10장을 읽는다.**

## 0. 공통 규칙

### 0-1. 숫자 표시 규칙 (다크 패턴 금지)

| 규칙 | 값 |
|---|---|
| 보이는 수 | **오늘 몫만.** 오늘 몫 = min(오늘 할 카드, 하루 상한 남은 수). 밀린 전체 수, '연체', '밀림'은 어디에도 쓰지 않는다 |
| 0일 때 | 아이콘째 숨긴다. "0"이나 "다 했어요" 글은 없다(끝 화면의 ✓만) |
| 색 | 숫자는 모노 `--text-2`. 빨강·주황 금지. 인주 점(`--seal`)은 시험 D-n 앞에만 쓴다 |
| 늘어나지 않기 | 세션 중 ↺로 다시 나오는 카드는 숫자를 늘리지 않는다(1-2 진행선 규칙) |
| 큰 수 | 그대로 쓴다(상한이 200이라 세 자리 이하). 후보 수만 99를 넘으면 `99+` |

### 1-1. 시작

| | 가로 (글 구역 `(0.08, 0.22)–(0.40, 0.78)`) | 세로 · 폰 |
|---|---|---|
| 한 줄 | **`▤ 18`**: `IconReview` 22px + 모노 28px `--text-1` | 같음, 카드 구역 위쪽 |
| 주 동작 | 금빛 원 ▶ 52px, 한 줄 아래 20px | 같음 |
| 후보 점 | ▶ 오른쪽 16px에 `IconCandidate` 18px + 모노 13px 수(0이면 숨김, 2장) | 같음 |
| 새 출발 | 조건이 맞을 때만(1-5) ▶ 왼쪽에 `IconFresh` 20px 조용한 버튼 | 같음 |
| 툴팁(숫자) | "오늘 18 · 약 9분 · 새 4" | 길게 |

- **▶ 길게 누르기 = 둥근 메뉴 3칸:**
  - 12시 섞어서(기본)
  - 4시 과목 하나: 누르면 과목 점 줄이 나오고, 하나를 고르면 그 과목만 본다

- **오늘 몫이 0이면:** 숫자와 ▶를 숨긴다. 하늘의 성단은 고르게 켜져 있다. 후보가 있으면 후보 점만 남는다.

### 1-3. 끝 화면

- 카드 자리에 **✓ 하나**: 금빛 선 64px 원 + 체크. 체크는 선 그리기(stroke-dashoffset)로 360ms `out`이다.
- 툴팁(hover · 길게): "내일 12". 내일 몫이 0이면 툴팁도 없다.
- 하늘: 모든 별 최종 밝기 → V13 원반 +8% · 성단 V13s(M1 #25). 하루 1회.
- 4초 뒤 ✓는 흐림(40%)으로 남는다. 후보가 있으면 후보 점이 나타난다.

### 1-4. 섞기 · 하루 상한이 느껴지는 방식

- **섞기:** 화면 표시는 없다. 카드마다 과목 점 색이 바뀌는 것으로 느낀다(같은 과목 연속 3장 이하, 엔진).
- **상한:** 시작 숫자가 늘 오늘 몫이다. 넘친 카드는 다음 날들로 고르게 나뉘고, 그 사실은 1-1 툴팁에도 쓰지 않는다.
- **새 카드:** 과목 점이 빈 고리다. 하루 20(설정)까지 섞여 나온다.

## 3. 떠올리기 모드 (앱 A · 손글씨)

### 3-1. 입구

- 노트 종이 머리 오른쪽 `IconRecall` 16px. 본문이 80자 이상이거나 필기 1쪽 이상일 때만 보인다.
- ⋯ 메뉴 '떠올리기', ⌘K '떠올리기', 키 `⌥R`.
- 오늘 줄의 `✎ 2`(4-3)를 누르면 오늘 떠올릴 첫 노트가 이 모드로 열린다.

### 3-2. 흐름 (4단계, 글 0줄 — 제목은 데이터)

| 단계 | 화면 | 동작 · 모션 |
|---|---|---|
| ① 가리기 | 본문이 종이색 안개로 덮인다(제목만 남음) | 위 → 아래로 320ms `--ease-out` 마스크. 하늘은 쉼 |
| ② 쓰기 | 같은 종이가 빈 칸이 된다. 키보드면 글, 펜이 닿으면 잉크 | 오른쪽 아래 금빛 ✓(⌘Enter) = 다 썼음. 안개 위를 길게 누르면 1초 엿보기(엿본 횟수는 기록만, 표시 없음) |
| ③ 비교 | 나란히: 왼쪽 내 글, 오른쪽 원문 | 원문 칸이 220ms opacity로 들어온다. 원문에서 내 글과 겹친 문장은 `--text-3`, **빠진 문장은 `--text-1` + 왼쪽 2px 금 막대** |
| ④ 빠진 곳 → 후보 | 빠진 문장을 누르면 점선 테두리 + `IconCandidate`가 붙는다(다시 누르면 취소) | 끝 ✓를 누르면 고른 것들이 후보(출처 아이콘 `IconRecall`)가 된다. 하늘: 노트 별 +20%(V3), 시험 계획의 '떠올리기 1번'으로 센다 |

- **빠짐 판정(글 노트):** 원문 문장마다 한글 2-gram이 내 글에 들어 있는 비율이 0.35 미만이면 빠짐이다. 굵은 글씨 · `[[링크]]` 낱말이 빠지면 0.35 이상이어도 빠짐이다.
- **필기 노트:** 원문은 쪽 그림이라 자동 판정이 없다. 비교 단계에서 원문 쪽을 올가미로 고르면 선택 칸에 `IconCandidate`(후보로)가 더해진다. 앞면은 그 영역을 덮은 그림, 뒷면은 걷은 그림이다(테이프 카드와 같은 그림 API).

### 4-2. 계획 띠 위의 날별 표시 (글 없이)

계획 장소의 수평 띠 = 시간축(design-m1 0-1 `band(d)`: x = 0.10 + 0.80 × min(d, 14)/14). 날 표시는 DOM · SVG 덧층으로 띠 바로 위에 둔다(가로 y = 띠 위 가장자리 − 6px, 세로 · 폰 같은 규칙).

| 날 | 모양 |
|---|---|
| 공부 날(미래) | 세로 막대 폭 3px, 높이 = 그날 몫에 비례(최대 28px), `--text-3` 35%, 모서리 1.5 |

- **툴팁(hover · 길게):** "▤ 18 · ✎ 2"(아이콘 + 숫자).

## 5. 기억 밝기 (모션 · 앱 A)

| 항목 | 값 |
|---|---|
| R(노트) | 그 노트 카드들의 평균 retrievability(지금 시각). 카드가 없는 노트는 기억 밝기에서 빠진다(M2 링크 밝기 그대로) |
| 밝기 매핑 | **b = clamp(0.40 + 0.60 × (R − 0.50) / 0.45, 0.40, 1.00)**. R 0.95 이상 = 100%, 0.50 이하 = **하한 40%** |
| 크기 | M2 그대로(링크 수, 1.6–2.2px). 기억은 밝기와 색만 바꾼다 |

| 복습 성단 | 카드 별 하나 = 카드 하나. 같은 매핑을 쓴다. 오늘 할 카드는 안쪽, 새 카드는 1.2px 푸른 흰빛 50% |

## 10. 꼭 알 것 · 리더 결정

**구현자가 꼭 알 것**
1. **(앱 A) 숫자는 오늘 몫만, 진행선은 뒤로 가지 않는다.** "i / n"과 밀린 수는 화면에 없다. 세션 안 ↺ 카드는 수를 늘리지 않는다.
2. **(앱 B) 계획 띠의 날 표시는 `band(d)`와 같은 x를 쓴다.** 막대 = 그날 몫, 빈 고리 = 쉬는 날, 줄표 = 여유 날. 오늘 화면 한 줄은 4-3 순서를 따른다.
3. **(손글씨) 테이프 카드 = 쪽 영역 그림 두 장(덮음 · 걷음).** 뒤집기는 크로스페이드가 아니라 테이프 걷힘 모션이다. 필기 떠올리기의 후보도 같은 그림 API를 쓴다.
4. **(모션) 하루치 = 선 하나, 날짜가 아니라 순서대로 긋는다.** 하지 않은 날은 흔적이 없다. 기억 밝기 하한은 40%이고 하루 1번만 바뀐다.

**리더 결정이 필요한 것**
1. **복습 진행 표시:** M3의 '1 / 13'을 진행선(뒤로 가지 않음)으로 바꾼다.
2. **후보함 가로 판 자리:** `(0.08, 0.10)–(0.42, 0.90)`. `review` 가로 마스크에 사각형 하나를 더해야 한다(모션).
3. **새 출발이 보이는 조건:** 주 · 학기 경계 + 상한을 넘는 날이 3일 이상. 그 밖에는 ⌘K와 설정에만 둔다.
4. **떠올리기 빠짐 판정:** 2-gram 0.35 기준(굵은 글씨 · 링크 낱말은 늘 검사). 필기 노트는 올가미로 직접 고른다.
5. **시험 뒤 시험 별을 나의 가지로 옮기기:** 보이지 않을 때 옮긴다(M1 #43과 같은 방식).
6. **목표 기억률 5칸**(85 · 87 · 90 · 92 · 95): 브리프는 범위(0.85–0.95)만 정했다.
7. **엔진 API 제안 2개:** `renderTapeRegion(itemId, { covered, scale })`(손글씨), 날 몫 `planDay(date) → { cards, recalls, rest, buffer }`(앱 B). 이름은 담당자가 정한다.
