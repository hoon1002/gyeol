# M3 브리프 — 손글씨 · 조용한 화면 · 디테일 (리더 작성, 2026-10-17)

## 사용자 원문
> 아직 메모와 필기기능이 좀 부족해 보이는데 / 굿노트나 다른 필기앱 만큼의 기능에 부족함이 없으면 좋겠는데 / 지금 태블릿에서 펜으로 글을 쓸 수는 있는거야? / 다른 기능들도 추가할 것들 다 추가해줘
> 그리고 글씨를 최대한 없애보려 해보자 / 글이 있을수록 없어보여
> 최대한 디자인을 안 해치는데 많은 기능을 넣을 방안을 모색해봐
> 그리고 앱은 디테일이 생명이야 / 메인화면에서 별 누르면 확대되잖아 거기서 화면을 회전하려고 누르면 떼자마자 메인화면으로 돌아가 이런거 자잘한 문제들 다 찾아서 수정해주고
> 다른 연결할거 연결하거나 뭐 모션이나 등등 디테일을 최대한 살려줘 퀄리티 높게

## 답과 결정
- **지금은 펜으로 쓸 수 없다.** '필기' 노트는 미리보기 그림뿐이고, 펜 입력은 원래 M5였다.
- 그래서 **손글씨(원래 M5)를 지금 당긴다.** 로드맵은 이렇게 바뀐다: M3 손글씨·디테일 → M4 기억 엔진 → M5 리듬 → M6 녹음·공유.
- 목표는 '굿노트 수준에서 부족함 없음'이다. 다만 화면에는 거의 아무것도 없어야 한다.
- 원칙 세 가지:
  1. **글 0–1줄:** 화면마다 글은 많아야 한 줄이다. 나머지는 아이콘·숫자·하늘·모양으로 말한다. 처음 한 번만 짧게 알려 주고 사라진다.
  2. **기능은 숨어 있다가 필요할 때 나타난다:** 펜을 대면 도구가, 고르면 고른 것의 도구가 나온다. 길게 누르면 둥근 메뉴, ⌘K로는 모든 기능. 손가락 제스처를 쓴다.
  3. **디테일 0버그:** 누르기와 끌기를 구분하고, Esc·뒤로의 겹침 순서를 지키고, 전환 도중의 입력, 크기 바꾸기, 테마 바꾸기를 다 견딘다.

## 범위
### A. 손글씨 엔진 (src/ink/**)
- **입력:** PointerEvent(pen 압력·기울기, coalesced 이벤트), 손바닥 무시, 펜만 쓰기(펜이 감지되면 손가락은 넘기기·확대), 두 손가락 확대·이동.
- **도구:** 펜(볼펜·만년필 느낌), 형광펜(글 아래 곱하기, 곧게 붙기), 지우개(획 단위 + 부분 지우기), 올가미(옮기기·크기·회전·색 바꾸기·복사·붙이기·지우기), 도형 다듬기(그리고 잠깐 멈추면 선·화살표·사각형·원·삼각형으로), 글 상자, 사진 넣기, **가리개 테이프**(눌러서 보였다 가렸다 — 떠올리기 공부용).
- **쪽:** 틀 5종(빈·줄·모눈·점·코넬), 쪽 넘기기(세로 스크롤), 쪽 추가·순서·지우기, 쪽 썸네일 서랍.
- **되돌리기:** 되돌리기·다시하기(두 손가락 탭 / 세 손가락 탭, ⌘Z / ⇧⌘Z).
- **PDF:** 가져와서 쪽마다 배경으로 두고 그 위에 쓴다(pdfjs-dist). 내보내기는 PDF(획 포함, pdf-lib)와 쪽 그림.
- **성능:**
  - 펜 → 잉크가 다음 프레임 안에 그려진다(120Hz 기기 8ms 안).
  - 획 2,000개 쪽에서 넘기기·확대가 끊기지 않는다.
  - 저장은 획 단위다.
  - 쓰는 동안 하늘은 쉼(그리기 0)이다. 배터리와 GPU를 잉크에 몰아준다.
- **데이터:** schema v3(pages · strokes · pageItems, 리더가 넣음). 획 points는 Float32 [x, y, pressure, t], t는 녹음 싱크용이다.
- **백업:** strokes.points(ArrayBuffer)가 백업 왕복에서 깨지지 않아야 한다. JSON으로는 사라지니 바이너리 파일이나 base64로 넣는다. 왕복 시험에 포함한다.

### B. 메모 강화
- 메모 종류: 글 · 체크리스트 · 사진 · **손글씨 메모**(펜을 대면 메모 칸이 작은 잉크 칸이 된다) · 음성(MediaRecorder. localhost는 되지만 LAN http에서는 안 될 수 있음).
- 고정, 과목별 보기, 오래된 순·새 순, 메모 안 검색(검색 색인에 이미 있음).
- 별가루함에서 여러 개를 골라 한꺼번에 옮긴다.

### C. 조용한 화면 (글 줄이기)
- 모든 화면의 보이는 글을 목록으로 만들고, 남김·빼기·아이콘·길게 누르면 설명 중 하나로 정한다(아트 디렉터 design-quiet.md).
- 머리 제목·메타 줄·버튼 글자를 아이콘으로 바꾸고, 툴팁·첫 회 안내로 대신한다.

### D. 디테일 · 버그
- QA가 모든 화면과 상호작용을 훑어 버그 목록(team/qa-m3.md)을 만든다. 담당자가 고친다.
- 사용자가 직접 본 버그: **오늘에서 별을 눌러 다가간 뒤, 돌리려고 끌었다 떼면 메인으로 돌아간다.**
  - 누르기와 끌기를 구분해서(이동 6px 또는 시간 기준) 끌기 뒤의 click은 무시한다.
  - 별에 다가가 있는 동안은 그 별을 중심으로 돈다.
- 연결과 모션 디테일: 전환·눌림·완료의 손맛(눌림 크기·스프링·하늘 반응), 빈 상태, 불러오는 중 상태.

## 하지 않는 것 (다음 마일스톤)
FSRS·카드 추출·시험 역산(M4), 의식·주간 회고(M5), 녹음–필기 싱크·공유(M6), 손글씨 글자 인식(OCR).

## 완료 기준
- 펜(압력) · 손가락 · 마우스로 쓰기, 손바닥 무시, 도구 9종, 쪽 틀 5종, PDF 가져와 쓰고 내보내기, 되돌리기, 가리개 테이프가 동작한다.
- 잉크 지연은 다음 프레임 안이다. 획 2,000개 쪽에서 넘기기·확대 최장 프레임 ≤ 20ms다.
- 보이는 글이 화면마다 1줄 이하다(아트 디렉터 표 기준). 기능은 하나도 잃지 않는다(⌘K·길게 누르기·툴팁으로 닿는다).
- QA 목록의 '상'·'중'이 0이고, 사용자가 말한 별 다가가기·회전 버그가 고쳐져 있다.
- 콘솔 오류 0, typecheck·build 통과, 백업 왕복(획 포함) 그대로, 첫 화면 JS 증가 ≤ 15KB gzip(잉크는 지연 청크).

## 공통 규칙
- 패키지는 리더만 설치한다. 이미 설치됨: perfect-freehand, pdfjs-dist, pdf-lib, TipTap, fflate.
- 브라우저 시험:
  - 사용자 미리보기 탭과 대시보드 탭은 건드리지 않는다.
  - 헤드리스 크롬은 작업 폴더 안 임시 프로필로만 쓰고, 끝나면 끄고 프로필을 지운다. CDP Input.dispatchMouseEvent pointerType 'pen' · force · tiltX/Y로 펜을 흉내 낼 수 있다.
  - 또는 미리보기 새 백그라운드 탭 하나만 쓴다.
- 사용자 데이터를 바꾸지 않는다. 시험 데이터는 격리 프로필이나 시험 모드에서만 만든다.
- 진행 표시는 `team/status/<키>.json`이다(ink, inkd, qa, ad, app, app2, fx). 진행 표시마다 5시간 한도를 확인하고, 95% 이상이면 정리하고 보고한다.
- 커밋은 리더만 한다.

## 리더 결정 (아트 디렉터 design-quiet.md 반영, 2026-10-17)
1. **복습 평가는 M3에서 2개로 바꾼다:** ↺(다시) / ✓(알았음)이고, ✓를 길게 누르면 어려움·알맞음·쉬움 3단계가 나온다. 저장하는 평가 값 4종은 그대로라 M4 FSRS와 맞는다. 처음 10장만 버튼 아래에 낱말을 흐리게 보인다.
2. **'부르면 나오는 말'은 '1줄'에 세지 않는다:** 메뉴·툴팁·되돌릴 수 없는 일의 확인·오류가 여기에 든다. 단, 1–2낱말이어야 한다. 늘 보이는 앱의 말만 화면당 1줄 이하로 센다.
3. **오늘의 한 줄 규칙을 승인한다:** lib/situation.ts를 다시 쓴다(앱 B).
4. **첫 실행 0단계(브랜드 소개)를 없앤다.** '나중에'는 ✓에 합친다. 은하 자체가 첫인상이다.
5. **⌘K 미리보기는 노트 본문 미리보기만 남긴다.** 명령 설명 줄은 모두 뺀다.
6. **아이콘은 한 체계(24 격자 · 선 1.5)로 쓴다:**
   - 앱 아이콘은 src/shell/icons.tsx(앱 B)에 둔다.
   - 손글씨 도구 아이콘은 src/ink/ui/icons.tsx(손글씨 엔진 개발자)에 같은 규격으로 둔다.
   - 겹치는 이름(지우개·올가미 등)은 손글씨 쪽이 shell에서 가져다 쓴다.
7. **툴팁·첫 회 안내는 앱 B가 공용으로 만든다:** `<Tip>`과 `useHint(id)`(src/shell/Tip.tsx · src/shell/hints.ts). 모두가 이것을 쓴다.

## 리더 결정 (손글씨 설계자 design-ink.md 반영, 2026-10-17)
1. **하늘 API 추가 (모션 개발자):**
   - `useSkyPaper(open)`: 노트를 펼치면 띠가 화면 밖으로 나가고, 노출 0.5, 쉼.
   - `pinDust(id, on)`
   - '잉크가 별이 된다'는 이미 있는 `inkSettled(noteId, { pages? })`에 쪽 수 인자를 더해 쓴다(새 이름 inkToStar는 만들지 않음).
2. **스키마는 버전을 올리지 않는다.** 색인이 필요 없는 필드라 타입만 더했다(리더 반영 완료).
   - Memo: kind · items · pinned · pageId · durationMs
   - PageItem: flag
   - 손글씨 메모의 쪽은 pages.noteId = 'memo:' + 메모 id로 둔다.
3. **펜 길게 누르기 → 둥근 메뉴는 기본 켬이다.** ⌘K와 설정에서 끌 수 있다.
4. **'입력한 손이 정한다'를 기본으로 한다:** 새 노트·＋를 펜으로 누르면 필기 노트·손글씨 메모, 손가락·키보드면 글 노트·글 메모.
5. **도구 칸 기본 자리는 위 가운데다**(폰은 아래 가운데).
6. **음성 메모 → 노트로:** 글 노트에 소리 칩 블록(TipTap 노드)을 둔다(앱 A).
7. 툴팁·아이콘 값은 design-quiet와 design-ink가 같은 값이다(hover 600ms · 선 1.5 · 24 격자). 전역 구현은 앱 B의 Tip.tsx를 쓴다.
